## 5. 命名与去重约定

1. **一事一文**：每个主题只有一份权威文档；其他位置一律写"见 `X.md` §N"。
2. **合并而非并列**：若两份文档内容重叠超过约 1/3，应合并并删除原件，同时在卷首注明"本文由 … 合并并取代二者"。
3. **删除前先改交叉引用**：全仓引用检查命令

   ```bash
   grep -rn "被删文件名" --include="*.md" --include="*.py" --include="*.rst" .
   ```

4. **口径统一优先**：同一物理量在不同文档/脚本中若数值不一致，必须先钉死口径再引用（当前待办见 §3 末行）。
