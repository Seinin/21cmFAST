## Purpose

规定「物理链」页（第三页）的分层与说话口径：一级只讲物理过程，旁路与实现细节默认收起且一键可达，代码与文献作为证据默认收起，本页检索与状态条都按本页自己的数据说话。

## Requirements

### Requirement: 一级只呈现物理主链

物理链页的一级（根视图的默认状态）SHALL 只呈现物理主链的过程框与它们下辖的量。旁路 / 诊断出口阶段（真源里位于 S04 的量及其过程框）与工程实现节点 MUST NOT 出现在一级。「哪些阶段属于物理主链」MUST 只有一份声明（生成器与自检共用同一份），视图 MUST 按生成物里的分层标记渲染、MUST NOT 写死阶段名单。

#### Scenario: 默认状态下列不出旁路框

- **WHEN** 打开物理链页，不做任何展开操作
- **THEN** 一级上只有物理主链的过程框；旁路阶段（S04）的过程框与它下辖的量都不在可见集里

#### Scenario: 默认状态下列不出工程项

- **WHEN** 打开物理链页，不做任何展开操作
- **THEN** 一级上不出现任何工程项节点（`kind: engineering`）

#### Scenario: 一级框集合等于主链口径（可证伪）

- **WHEN** 运行物理链自检
- **THEN** 默认可见的一级过程框集合恰好等于分层声明里的物理主链阶段名单——多一个（例如旁路阶段被摆回一级）或漏一个都判失败，并指出是哪个阶段

#### Scenario: 口径改了视图不用改

- **WHEN** 把某个阶段从物理主链名单移到旁路名单并重新生成
- **THEN** 页面按新的分层标记渲染（该阶段的框离开一级、进入收起条），页面代码无需改动

### Requirement: 旁路与实现细节默认收起且一键可达

工程实现节点 MUST 挂在「实现细节」话题上，旁路阶段 MUST 带分层标记，二者在页面默认状态下 MUST 都处于收起。页面 SHALL 自带一条常驻折叠条，标题写明它收纳什么、有多少项、以及它们不属于物理链；点击即一键展开 / 收起。展开 MUST 让被收起的旁路框与工程节点同时可见、可选中。展开入口 MUST NOT 只存在于检查器里。

#### Scenario: 折叠条写明内容与数量

- **WHEN** 查看页面上的折叠条（收起状态）
- **THEN** 标题写明它收纳的是旁路与实现细节、给出项数，并注明这些不属于物理链

#### Scenario: 一键展开

- **WHEN** 点击折叠条的展开按钮
- **THEN** 旁路过程框与工程节点同时出现在画布上（旁路框待在它自己的道里，不混进主链），再点一次恢复收起

#### Scenario: 展开后对象照常可用

- **WHEN** 展开折叠条后选中其中的一个工程节点
- **THEN** 检查器给出它的完整信息（含证据入口），与物理量走同一套交互

#### Scenario: 检查器入口不回归

- **WHEN** 在检查器里点「实现细节」话题
- **THEN** 折叠条同步展开，两个入口指向同一个状态（不出现"看着开了其实没开"）

### Requirement: 工程项的归属纪律

生成物里的工程项（`kind: engineering`）MUST 带 `topic:impl` 话题，非工程项 MUST NOT 带；「实现细节」话题 MUST 在话题注册表里。自检 SHALL 断言这两条，而不是只断言"存在工程节点"。

#### Scenario: 话题归属与种类一致

- **WHEN** 运行物理链自检
- **THEN** 每个工程项都带 `topic:impl`、每个非工程项都不带；有不一致就失败并列出节点 id

#### Scenario: 话题在注册表里

- **WHEN** 运行物理链自检
- **THEN** 「实现细节」话题在注册表里（否则关闭它没有对象，收起条就是摆设）

### Requirement: 代码与文献是默认收起的证据

在物理链页，选中任何对象时 MUST NOT 直接列出源码文件路径、行区间或落点计数。代码落点与文献引用 SHALL 各由一个默认收起的入口呈现，入口写明数量（如「看实现 (N)」「看文献 (M)」），展开后才出现文件与行区间 / 引用点，点击即就地打开源码预览或文档阅读。该纪律只作用于物理链页：画布页的引用列表 MUST 保持原样。

#### Scenario: 展开前没有文件与行号

- **WHEN** 在物理链页选中一个物理量或它的过程框，查看检查器
- **THEN** 检查器里不出现任何源码文件路径、行区间或落点计数

#### Scenario: 「看实现」展开后才出现落点

- **WHEN** 点击「看实现」
- **THEN** 列出该对象的文件与行区间；点击其一即打开源码预览并定位到那几行

#### Scenario: 「看文献」独立入口

- **WHEN** 点击「看文献」
- **THEN** 列出该对象的论文引用点；点击即打开文档阅读

#### Scenario: 画布页不受影响

- **WHEN** 在画布页选中一个带引用的节点
- **THEN** 引用列表按原有方式直接显示（不被"默认收起"改掉）

### Requirement: 本页检索与来源标注

物理链页的检索 MUST 只用本页生成物（`physics-chain.json`），MUST NOT 使用画布页的数据，也 MUST NOT 改动画布页的选中状态。检索 SHALL 覆盖四路：参数、物理量、过程名、论文出处。每条命中 MUST 标注它属于哪一层（物理链 / 旁路与实现细节）。选中命中项后 MUST 在本页定位（选中该对象）；若它属于被收起的那一层，MUST 自动展开折叠条后再选中。

#### Scenario: 命中参数

- **WHEN** 在物理链页检索一个参数名（如 `F_STAR10`）
- **THEN** 结果给出它作用的物理量与它门控的开关边，并注明数量

#### Scenario: 命中只存在于收起条里的对象

- **WHEN** 检索一个只存在于收起条里的对象（旁路阶段的诊断量或工程节点）
- **THEN** 该结果标注「旁路与实现细节」；选中后折叠条自动展开并选中该对象

#### Scenario: 命中过程名与论文出处

- **WHEN** 检索一个过程名（如「天体物理源」）或一处论文出处
- **THEN** 分别命中对应的过程框 / 带该出处的量，并在结果里标注来源

#### Scenario: 不污染画布

- **WHEN** 在物理链页检索并选中一个结果，然后切回画布页
- **THEN** 画布页的选中状态与它的数据没有被这次检索改动

#### Scenario: 切视图清空检索词

- **WHEN** 从任意一页切到另一页
- **THEN** 检索词与检索面板回到空状态（两个方向都清，不把一页的关键词带进另一页）

### Requirement: 状态条报本页口径

物理链页底部的状态条 SHALL 报本页的规模与当前对象：物理过程数、子过程数、参数数、文献数，以及当前打开的是哪个对象（节点还是连线、以及它的名字）。在物理链页，状态条 MUST NOT 报画布页口径（画布节点数与关系数、画布布局、画布缩放、当前标签页可见数、保存状态与未保存提示）。切回画布页时 MUST 恢复画布口径。

#### Scenario: 物理链页的规模

- **WHEN** 打开物理链页
- **THEN** 状态条显示物理过程数、子过程数、参数数、文献数（数量取自生成物，不写死），且不出现画布节点数、画布缩放或保存状态

#### Scenario: 当前打开的对象

- **WHEN** 在物理链页选中一个物理量或一条连线
- **THEN** 状态条写明当前打开的是节点还是连线、以及它的名字

#### Scenario: 切回画布恢复画布口径

- **WHEN** 从物理链页切回画布页
- **THEN** 状态条恢复显示画布口径（节点/关系数、布局、缩放、本视图可见数、保存状态）

### Requirement: 一级摆位的尺寸与距离同源

物理链页一级的摆位 MUST 由**两个数**决定，且只能是这两个数：**框的宽高**问尺寸口径（`src/graph/labels.ts`，与画布画框用的是同一套公式），**间距**是一个与框大小无关的常数（`GAP`）。生成器 MUST NOT 用写死的框尺寸去铺坐标（同一份"框有多大"不许有两套数）。

由此 MUST 成立三条：

1. **成比例**：块、块内成员、成员内步骤、框外带，一律按各自的实测宽高依次让开，间距恒为 `GAP`；每排的高度 MUST 取该排最高的框，排间空隙同样恒为 `GAP`。同一块的成员 MUST 仍与自己块同一条水平带（y 相同）。
2. **距离不过大**：任何相邻两框之间的空隙 MUST NOT 超过这两框里**较小的那条短边**（空的地方不许比实的地方还大）。
3. **全图一个间距**：同排的块、同块的成员、同成员的步骤、相邻两排，量到的空隙 MUST 是同一个数（四处排法各自独立，但必须落在同一个间距上）。

尺寸口径在脚本侧 MUST 只有一份副本（`scripts/lib/boxSize.mjs`），且该副本与 `labels.ts` MUST 逐字同口径；脚本内部 MUST NOT 各自再写一份尺寸公式。自检 MUST 用**画布的口径**（真跑 `labels.ts`）量框，MUST NOT 抄一份公式来量。

#### Scenario: 框大，整片跟着大

- **WHEN** 某个块的名字变长（折成两行、框高从 38 变成 45）并重新生成
- **THEN** 它所在那一排的行高随之变成 45，下一排整体下移；排间空隙仍是同一个常数

#### Scenario: 写死步长会被当场抓住

- **WHEN** 把某一处的间距改回写死的坐标步长（如 300）并重新生成
- **THEN** `npm run check:chain` 失败，报出量到的两个间距值（如 `182.5 / 24.0`），退出码 1

#### Scenario: 距离不许比尺寸还大

- **WHEN** 生成物里出现一个空隙大于相邻两框较小的那条短边（如空隙 182.5、短边 38）
- **THEN** 自检报出这对框与两个数，失败

#### Scenario: 两份口径漂移会被发现

- **WHEN** 只改了 `labels.ts`（或只改了 `scripts/lib/boxSize.mjs`）的字号 / 内边距 / 折行规则
- **THEN** 生成物的坐标（按副本算）与画布尺寸（按 `labels.ts` 算）不再吻合，空隙不再是同一个数，`check:chain` 的「全图一个间距」断言失败

#### Scenario: 不打开浏览器也能读到"字多大"

- **WHEN** 跑 `npm run check:chain`
- **THEN** 输出里有一行 `一级版面 <宽> × <高>（框 <宽域> 宽 × <高域> 高，空隙 <值>）：取景倍数 ≈ 画布高 / <高>，屏幕字号 = 13 × 那个倍数`

### Requirement: 左栏并排两个检索面

物理链页左栏 SHALL 提供两个并排的检索面：「参数」与「天体物理过程」，以页签切换，默认打开「参数」面且行为与现状一致。两个面的词条 MUST 都取自本页生成物（`physics-chain.json`），视图 MUST NOT 写死任一面的人手名单。过程词条 MUST 给出三条信息：过程名、它下辖的量数、它用到的论文出处数（论文出处口径与本页「文献」那一路同源）。某一面为空时 MUST 写明原因，MUST NOT 渲染成空面板。

左栏 MUST NOT 再出现跨分组的「代码类」总计数徽标（各分组头上的条数不受影响）。切换页签 MUST NOT 改动画布选中与画布数据，MUST NOT 丢弃另一面的词条数据，也 MUST NOT 清空画布页状态。

#### Scenario: 默认打开参数面且没有代码类总计数

- **WHEN** 打开物理链页、检索框为空
- **THEN** 左栏显示「参数」面（参数词条按代码类名分组、各组带条数），且**不出现**「N 个代码类」这类跨分组总计数徽标

#### Scenario: 切到过程面

- **WHEN** 点击左栏的「天体物理过程」页签
- **THEN** 词条换成过程清单，每行写明过程名、它下辖的量数与它用到的论文出处数；参数面收起但数据未被丢弃

#### Scenario: 来回切页签不改选中

- **WHEN** 在画布上选中一个量，然后切到过程面再切回参数面
- **THEN** 画布选中对象与画布数据与切换前一致

#### Scenario: 名单改了视图不用改

- **WHEN** 在真源里增删一个过程并重新生成
- **THEN** 左栏过程面按新名单渲染，页面代码无需改动

### Requirement: 天体物理过程清单的单一真源

过程清单 MUST 只有一份声明：真源 `docs/notes/physics-chain/chain.json` 的 `processes`（一条 = 一个过程：名字 + 成员 id + 主块 + 它对应的论文拟合律 / 公式出处），生成器 MUST 原样烘进生成物。

过程名 MUST 是「按论文等式打包」的物理过程（如 `Lyα 耦合`、`气体热史`、`自旋温度`），MUST NOT 与一级的代码模块块（`M1`…`M10`）混为一谈，MUST NOT 再引入一套圆圈数字编号（同屏已有三套 `⓪`…`⑨`）。过程面 MUST NOT 用 `order` / 档位做筛选或排序。

自检 MUST 独立重算并断言：每个量与驱动量**恰好**属于一个过程或一条带（不重不漏），且每个成员 id 在真源里存在。不满足时 MUST 失败并列出漏掉、重复或悬空的 id。

#### Scenario: 不重不漏

- **WHEN** 运行物理链自检
- **THEN** 过程与带的成员并集恰好等于生成物里的全部量 + 驱动量；多一个、少一个或有一个成员同时出现在两条过程里都判失败，并列出相关 id

#### Scenario: 成员悬空被抓

- **WHEN** 在真源 `processes` 里写一个不存在的成员 id 并重新生成
- **THEN** 自检失败并指出该 id

#### Scenario: 名字不是一级块名

- **WHEN** 查看过程面词条
- **THEN** 出现的是过程名（如 `Lyα 耦合`），不出现 `M8`、「气体热与自旋温度」这类代码模块块名

#### Scenario: 过程面不按档位筛人

- **WHEN** 改动某个块或成员的 `order` 并重新生成
- **THEN** 过程面的词条集合、顺序与筛选结果都不变

### Requirement: 过程与参数互为矩阵

过程面与参数面 MUST 互为反查。在过程面点中一个过程，MUST 在本页定位到它的主块并选中（复用既有的定位与选中），并点亮参数面里与它相关的参数；在参数面点中一个参数，MUST 点亮过程面里读了它的过程。反查口径 MUST 复用既有的「参数 × 节点矩阵」，MUST NOT 另造一份参数归属表。两侧计数 MUST 由生成物算出，MUST NOT 写死。某个过程与任何参数都无关系时，MUST 显式写明「无」，MUST NOT 静默呈现为空。

#### Scenario: 点过程定位并点亮参数

- **WHEN** 在过程面点中 `Lyα 耦合`
- **THEN** 画布定位到它的主块 `M8 气体热与自旋温度` 并选中该块，参数面里与它的成员量（`jalpha` / `xalpha`）有关系的参数被点亮；一个都没有时写明「无」

#### Scenario: 点参数点亮过程

- **WHEN** 在参数面点中一个参数 `P`
- **THEN** 过程面里成员量读了 `P` 的那些过程被点亮

#### Scenario: 反查口径同源

- **WHEN** 运行物理链自检
- **THEN** 由过程反查出的参数集合，与「参数 × 节点矩阵」按同一成员量算出的结果逐条一致（没有第二份归属表）

### Requirement: 兜底小节承载带与未归属的量

过程面 MUST 用一个常驻、默认收起的小节承载**不是过程**的两条「带」（`环境与给定`、`观测量`）与旧划分覆盖不到的量。小节标题 MUST 写明它收纳什么、有几项、以及它们不是过程。展开后这些项 MUST 可选中、可定位到它的块，与过程词条走同一套交互；默认状态下它们 MUST NOT 混在过程词条之间。

#### Scenario: 小节写明内容与数量

- **WHEN** 查看过程面的收起小节（收起状态）
- **THEN** 标题写明它是「带与未归属的量」、给出项数，并注明它们不是过程

#### Scenario: 一键展开可用

- **WHEN** 点击展开
- **THEN** 两条带与未归属的量出现在词条里，可选中并定位到各自的块；再点一次恢复收起

#### Scenario: 不与过程混排

- **WHEN** 过程面处于默认状态
- **THEN** 带与未归属的量不出现在过程词条之中，只出现在兜底小节里
