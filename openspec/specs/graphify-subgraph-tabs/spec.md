# graphify-subgraph-tabs Specification

## Purpose
把「了解模块细节」从原地展开改为显式的子图导航：装饰容器（大框）只作视觉分组，若干大模块摆放在框内；模块是可进入的导航单位——双击或属性页入口在新标签页打开其内容；标签页之间自由切换，当前位置同步到 URL。

## Requirements

### Requirement: 装饰容器与模块的可见性规则

带有子节点的节点 MUST 二选一：`type` 为 `group`（大框）的**装饰容器**，或**模块**（非 `group` 类型）。每个标签页 MUST 渲染其焦点节点的「可见内容」：焦点的直系子节点；其中装饰容器的子节点 MUST 递归地内联渲染在该装饰框内部（框自动合围其子节点），模块的子节点 MUST NOT 与其父节点同屏出现。装饰容器 MUST NOT 提供进入/展开交互，纯作视觉分组；模块 MUST 以紧凑尺寸呈现（尺寸由标题决定，而非子节点合围）。标签页内 MUST 只绘制两个端点都在本标签页可见的边（端点可位于装饰框内部）；跨层关系不绘制，但 MUST 能在属性页中查看。

#### Scenario: 主图 = 装饰大框内的五个层模块

- **WHEN** 打开图谱（无 URL 参数）
- **THEN** 主图标签页显示 `图一` 装饰大框，框内只显示 ①入口层、②编排层、③备料层、④红移循环、⑤输出层 五个层模块及它们之间的流向边，不显示任何层内节点

#### Scenario: 装饰容器内联渲染子节点

- **WHEN** 打开「入口 B · 三个顶层驱动」的子图标签页
- **THEN** 画布显示 E1/E2/E3 三个装饰 lane，每个 lane 的步骤节点直接画在各自 lane 框内（即图二的样子）

#### Scenario: 模块的子节点不同屏

- **WHEN** 打开「③备料层」的子图标签页
- **THEN** `compute_initial_conditions` 以紧凑模块形式呈现（带 ▸ 徽标），其下的 S09 框与框内节点不显示；进入该模块自己的标签页后才显示 S09 框及其内容

### Requirement: 进入子图的入口

模块 MUST 提供两个进入子图的入口：双击该模块；以及在属性页中显示「进入子图 ↗」按钮。单击节点 MUST 保持选中语义（属性页显示其属性），不得直接进入子图。装饰容器与叶子节点 MUST NOT 成为标签页焦点：双击装饰容器 MUST NOT 产生任何导航。进入子图时：若该模块已有标签页 MUST 激活它，否则 MUST 新建标签页并激活。

#### Scenario: 双击模块打开子图

- **WHEN** 双击「②编排层」模块
- **THEN** 打开（或激活）以「②编排层」为焦点的标签页，显示其 3 个直系子节点

#### Scenario: 属性页入口

- **WHEN** 选中一个模块并在属性页点击「进入子图 ↗」
- **THEN** 与双击等效地打开（或激活）该模块的子图标签页

#### Scenario: 单击不进入

- **WHEN** 单击一个模块
- **THEN** 该节点进入选中态，属性页显示其属性，标签页不发生任何变化

#### Scenario: 双击装饰容器不导航

- **WHEN** 双击主图中的 `图一` 大框（非子节点区域）
- **THEN** 不打开任何标签页，选中状态按常规单击语义处理

### Requirement: 标签栏与标签页状态

画布上方 MUST 有一条标签栏，按打开顺序列出全部标签页。「主图」标签 MUST 固定在最前且不可关闭；其余标签 MUST 可关闭。单击标签切换激活；关闭当前激活的标签后 MUST 激活其左侧相邻标签。每个标签页 MUST 独立保持自己的缩放、平移与选中状态，切换标签时不丢失。只有模块（非 `group` 类型且带有子节点的节点）才能成为子图标签页的焦点。

#### Scenario: 标签页各自记住视口

- **WHEN** 在「④红移循环」标签页放大并平移到某处，切到主图再切回来
- **THEN** 该标签页的缩放与平移保持离开时的状态

#### Scenario: 关闭激活标签

- **WHEN** 关闭正在查看的子图标签页
- **THEN** 激活其左侧相邻标签页，且其余标签页状态不变

### Requirement: URL 同步与深链

当前激活标签页的焦点 MUST 同步到 URL 查询参数（主图不带参数）；加载带该参数的 URL 时 MUST 自动打开主图标签页与对应子图标签页并激活后者。参数指向不存在的节点、叶子节点或装饰容器时 MUST 回退到主图，不得报错中断。

#### Scenario: 复制链接还原现场

- **WHEN** 在「④红移循环」标签页复制地址栏 URL 并在新窗口打开
- **THEN** 新窗口显示主图与「④红移循环」两个标签页，且后者处于激活态

### Requirement: 主图层带与模块结构

主图 MUST 按图一的逻辑组织：**层是容器、模块是类 / 函数**。
- 根层恰为 ①入口层、②编排层、③备料层、④红移循环、⑤输出层 五条**层带**（装饰容器，`group`），自顶向下排列，带内直接放这一层的**模块**（类 / 函数框）；MUST NOT 有把它们圈在一起的外层装饰框，MUST NOT 在层带之间画关系（层间先后由模块级流向与自上而下的排列表达）。
- 层带自身 MUST NOT 可进入；只有**带子结构的模块**才是可进入的导航单位。本图中 `compute_initial_conditions`（其下为 `初始条件（S09）` 装饰框）与「入口 B · 三个顶层驱动」（其下为 E1/E2/E3 三个装饰 lane）MUST 是可进入的模块。
- 不得存在 parent 指向已删除节点的孤儿节点。

#### Scenario: 主图就是五条层带

- **WHEN** 打开图谱（无 URL 参数）
- **THEN** 主图显示五条层带与带内的模块框，没有外层大框、也没有层带之间的连线；每条带里的模块横排

#### Scenario: 层带不可进入

- **WHEN** 双击 ②编排层 的层带本身
- **THEN** 不打开任何标签页（层带是容器，不是模块）

#### Scenario: 有子结构的模块可进入

- **WHEN** 双击 ③备料层 里的 `compute_initial_conditions`，再双击 ②编排层 里的 `入口 B`
- **THEN** 两个标签页分别显示：`初始条件（S09）` 框及其内 12 个过程节点与输入参数 `InputParameters`；E1/E2/E3 三条 lane 及其框内步骤

#### Scenario: 无孤儿节点

- **WHEN** 校验图谱数据
- **THEN** 每个非根节点的 parent 都指向一个存在的节点，且根层恰为五条层带

### Requirement: 容器不参与关系

装饰容器（`group`，含五条层带、S09 框、E lane）MUST NOT 参与任何关系：
- 数据侧 MUST NOT 存在任一端为容器的边；层与层之间的先后由模块级流向表达（如 `cli → 入口 A`、`_setup_ics_and_pfs_for_scrolling → compute_initial_conditions`）。
- 交互侧 MUST 阻止在容器上建立关系：选中容器时 MUST NOT 出现连线手柄；拖线吸附 MUST NOT 把容器当作目标；连线模式下点容器 MUST 给出提示并退出连线；右键菜单与属性页 MUST NOT 为容器提供「拉出关系」入口；建立关系对话框提交时 MUST 再次校验端点不是容器。

#### Scenario: 容器没有连线入口

- **WHEN** 在主图选中 ④ 红移循环 这条层带
- **THEN** 节点旁不出现连线手柄，属性页没有「从此节点拉出关系」按钮，右键菜单也没有该项

#### Scenario: 数据里没有涉及容器的关系

- **WHEN** 校验图谱数据
- **THEN** 没有任何边的端点是大框类型

#### Scenario: 连到容器会被拒绝

- **WHEN** 处于连线模式并点击某条层带
- **THEN** 提示「大框是容器，不参与关系」，且不创建关系、退出连线模式

### Requirement: 交付产物以边标签表达

交付产物（种子池、P(k)、δ_k、密度场、速度场、Coeval/LightCone/GlobalEvolution 等）MUST NOT 作为独立节点存在，其名称 MUST 写在「产出它的步骤 → 消费它的步骤」的边标签上（箭头文本）。解散产物节点时 MUST NOT 丢失流程信息：每个产物名至少出现在一条边的标签里。

#### Scenario: 产物不占画布

- **WHEN** 查看任一标签页
- **THEN** 画布上的方框只有函数/过程、驱动、参数变量、层与装饰框，没有「产物」方框；产物名只出现在连线标签上

#### Scenario: 产物随边一起显示

- **WHEN** 指针停在某条数据流连线上（或打开「显示边标签」开关）
- **THEN** 能读到该处流动的产物名称（如 `cosmo_consts 与 P(k)`、`lowres_density`）
