## MODIFIED Requirements

### Requirement: 可选支路必须在节点与关系上标注

只在特定配置下执行或存在的步骤 MUST 在**节点**上标 `conditional`，其相关**关系** MUST 同样标 `conditional`。生成器 MUST 把可选性写成数据字段，MUST NOT 只写在节点标题的文字里；且 MUST 校验"标题含可选字样 ⇔ 字段为真"。

**呈现口径**（本变更新改）：可选性 MUST NOT 由线型表达——线型已由「连线线型只用两种」占用（实线 = 交付、稀疏虚线 = 跨迭代）。条件关系 MUST 在**线上挂一枚开关框**（写明是哪个开关），线型与线宽随它所属的那一档；节点一侧 MUST 维持既有的虚线框呈现。图例里「条件 / 可选」条目 MUST 画出"线 + 线上挂框"。

注：下面的场景名沿用既有锚点（它写的是旧口径的"虚线"），内容已按新口径更新——关系一侧不再走虚线，改为挂开关框。

#### Scenario: 条件支路的节点与关系都是虚线

- **WHEN** 某个步骤只在特定参数取值下执行（如二阶修正只在 `PERTURB_ALGORITHM == "2LPT"` 时执行）
- **THEN** 该步骤的节点 MUST 呈现为虚线框；它与相邻节点的关系 MUST 保持所属那一档的线型，并在线上显示一枚写明开关名的框

#### Scenario: 可选性不能只写在标题里

- **WHEN** 生成器的节点声明在标题里写了"（可选）"却没有给出可选性字段（或反之）
- **THEN** 生成器 SHALL 报错，要求把二者对齐

#### Scenario: 同类型的条件边与非条件边只差一枚框

- **WHEN** 同屏对照一条条件边与一条同类型的非条件边
- **THEN** 两条的线型、线宽与颜色逐字相同，差别只在条件边线上多出那枚开关框
