## ADDED Requirements

### Requirement: 连线线型只用两种

画布上连线的**线型 MUST 只有两种**：**实线**与**稀疏虚线**。MUST NOT 出现点线（`dotted`）、MUST NOT 出现第二种虚线节奏（长划等）。每种线型 MUST 在一个语义上落地，MUST NOT 出现"两种语义共用一种线型、只靠猜"的情形。

**实线 = 产物交付**（依赖关系边，含两级：块间交付与块内交付；「对外输入」是它的更细更浅的弱化版）。**稀疏虚线 = 跨迭代**（跨红移回流，即"下一轮"）。线型 MUST NOT 用来表达"跳过了几步"——那由几何（道深）表达。

虚线 MUST 显式声明节奏（`line-dash-pattern`），MUST NOT 依赖渲染引擎的缺省节奏；节奏首项 MUST ≥ 8（模型单位），以保证在 0.5× 取景缩放下仍能看出是虚线。虚线的线宽 MUST ≥ 1.7。样式表里 MUST NOT 出现 `dotted`。

「条件 / 可选」MUST NOT 用线型表达（线型已无余量），MUST 由**挂在线上的一枚开关框**表达：框里写开关名，线型随它所属那一档。图例里的「条件 / 可选」条目 MUST 画出"线 + 线上挂框"，MUST NOT 只画一条虚线。

#### Scenario: 样式表里没有点线

- **WHEN** 运行 `npm run check:styles`
- **THEN** 断言样式表里不出现 `line-style: dotted`、且每条虚线规则都显式写了 `line-dash-pattern` 且首项 ≥ 8；违反即失败并指名那条选择器

#### Scenario: 虚线在取景缩放下仍可辨

- **WHEN** 把含虚线与实线的图缩到 0.5× 取景
- **THEN** 虚线仍看得出是断续的，MUST NOT 退化成与实线难以区分的灰线

#### Scenario: 条件不靠线型

- **WHEN** 同屏出现一条条件边与一条同类型的非条件边
- **THEN** 两条的线型与线宽相同，差别只在条件边线上多一枚开关框

#### Scenario: 图例节奏与画布同源

- **WHEN** 运行 `npm run check:canvas`
- **THEN** 图例每一档虚线样例的节奏 MUST 与该档在样式表里的 `line-dash-pattern` 逐字相同；漂移即失败并报出两个值

### Requirement: 画布只支持两种语义关系类型

画布数据的边类型 MUST 只有两种语义关系：**`depends_on`**（依赖）与 **`derives_from`**（派生）；可选性 MUST 作为它们之上的 `conditional` 修饰，MUST NOT 另立类型。类型声明、可选类型下拉、外观档位与图例条目 MUST 一并只保留这两种；MUST NOT 存在 `relates_to` / `contradicts` / `undirected` 的声明或外观（这三类在数据里一条都没有，留着只会让人以为图上少画了东西）。

新建边时 MUST 只能选这两种类型。自检 MUST 断言数据里不存在这三类边，且类型声明与外观档位里也不存在它们的名字。

#### Scenario: 数据里没有空类型

- **WHEN** 运行 `npm run check:graph`
- **THEN** 断言全部边的类型都在 `depends_on` / `derives_from` 之内；出现其它类型即失败并指名那几条边

#### Scenario: 声明与外观一起收窄

- **WHEN** 在类型声明或外观档位里搜 `relates_to` / `contradicts` / `undirected`
- **THEN** 一处都搜不到（不得只删数据、留下没人能触发的档位）

#### Scenario: 新建边只有两个选项

- **WHEN** 打开新建 / 编辑边的对话框
- **THEN** 类型下拉里只有「依赖」与「派生」两项

## MODIFIED Requirements

### Requirement: 层级连线与语义关系的样式区分

层级连线 MUST 在视觉上区别于语义关系：MUST NOT 绘制箭头，MUST 使用不高于语义关系的视觉权重（更细的实线、更低的饱和度）。由于交付边同样是实线（见「连线线型只用两种」），层级连线 MUST 靠**颜色更浅 + 线宽更细**与交付边区分，MUST NOT 靠线型区分；反之，语义关系里唯一的虚线档 MUST 只表示跨迭代，层级连线 MUST NOT 使用虚线。画布图例 MUST 同时列出「层级连线」与语义关系类型的区别。

#### Scenario: 层级连线无箭头且更淡

- **WHEN** 同时观察一条层级连线与一条依赖关系
- **THEN** 层级连线没有箭头、颜色更浅、线更细，依赖关系保持带箭头

#### Scenario: 两者都是实线但分得开

- **WHEN** 把这一屏缩到 0.5× 取景
- **THEN** 层级连线与交付边仍分得开（不是靠虚线，而是靠深浅与粗细）

#### Scenario: 图例含层级连线

- **WHEN** 打开画布图例
- **THEN** 其中除节点类型与关系类型外，还包含一条说明层级连线样式的条目

### Requirement: 跨红移回流的边样式与占位

物理链页的跨红移回流边 SHALL 有独立样式：与交付边在**颜色**上可区分（交付边为灰实线，回流为品红稀疏虚线），且 MUST 满足浅色画布底上的对比度要求。方向 MUST 靠箭头表达（回到上一轮，与段内自左向右的摆放方向相反），MUST NOT 只靠线型暗示方向。

开关关闭时这类边 MUST NOT 在画布上占位：MUST NOT 被悬停或点中命中、MUST NOT 遮挡任何标签或浮层、MUST NOT 撑开或改动画布视野。开关开合 MUST NOT 改变其余元素的样式与字号。

注：本变更把「交叉边（点线）」这一档整体撤掉（跨步依赖不再另立档位），下面这个场景名沿用既有锚点，内容已按新口径（与交付边对照）更新。

#### Scenario: 打开时与交叉边可区分

- **WHEN** 打开开关，同一屏上同时存在跨红移回流边与交付边
- **THEN** 两者的线型与颜色都不同（一为灰实线、一为品红稀疏虚线），回流边的箭头朝左（与摆放方向相反），可一眼分辨

#### Scenario: 关闭时不占位不命中

- **WHEN** 开关关闭，鼠标移到回流边原本所在的位置
- **THEN** 不命中该边，附近标签与浮层不被它遮挡，画布视野与坐标与关闭前一致

#### Scenario: 开合不牵动其余元素

- **WHEN** 反复开合开关
- **THEN** 其余边的线型、颜色、字号与标签逐字不变

### Requirement: 图例只列当前页实际渲染的种类与线型

图例的条目 MUST 由画布**当前实际渲染**的元素派生：节点条目只列本页出现的要素种类，线型条目只列本页真画出来的那些连线样式（**交付**、**跨红移回流**、**对外输入**、**条件 / 可选**四档之内）。MUST NOT 出现本页没有的条目，MUST NOT 用写死的固定清单代替派生结果。每个线型条目的色值、线型与虚线节奏 MUST 取自画布样式表同一来源，MUST NOT 在图例里另写一套。图例 MUST 随数据与开关变化即时更新：跨红移回流被开关藏起后，它那条条目一并消失，重新显现后回来。当前页一条线型都没有时，图例 MUST NOT 渲染线型那一段，不留下只剩标题的空壳。

样例线段 MUST 能表达该档的**形态**：「条件 / 可选」MUST 画成"线 + 线上挂框"，线型随所属那一档。

#### Scenario: 画布页只列本页真画的线型

- **WHEN** 打开画布页（图谱里只有 `depends_on` / `derives_from` 两种关系）
- **THEN** 图例里只出现本页真有的条目（交付、条件 / 可选），MUST NOT 出现跨红移回流、对外输入这类本页没有的条目

#### Scenario: 物理链页把回流与同红移内的数据流分开列

- **WHEN** 在物理链页打开图例
- **THEN** 图例同时含「同一红移内的数据流」与「跨红移回流」两条，前者是实线、后者是稀疏虚线，且两者的色值、线型与节奏各自与画布上那一档一致

#### Scenario: 藏起来的回流不留条目

- **WHEN** 关掉「跨红移反馈」开关，再打开图例
- **THEN** 图例里不再有跨红移回流那条；打开开关后它回来

#### Scenario: 没有线型就不留空壳

- **WHEN** 当前页一条连线都没画（例如只有孤立节点）
- **THEN** 图例不渲染线型那一段

#### Scenario: 档位总数收敛

- **WHEN** 数一数线型档位的总数
- **THEN** 不超过四档（交付、跨红移回流、对外输入、条件 / 可选）；MUST NOT 出现「跨层捷径」「相关」「相斥」「无向关系」这些档
