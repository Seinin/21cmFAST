## ADDED Requirements

### Requirement: 导入写盘后回读校验

导入工具在把草案写入图谱数据文件之后 MUST 重新读取落盘文件，并比对关键字段指纹：已注册话题数量、节点话题归属总条数、节点总数、引用总数。任一指纹与写入前不一致时 MUST 报错退出（非零退出码），列出发生差异的字段与两侧数值，并给出「服务端 schema 可能落后于源码，请重启 dev 服务后重试」的提示；MUST NOT 静默视为成功。

#### Scenario: 字段完整时导入成功

- **WHEN** 导入一份含话题注册表与节点话题归属的草案，且落盘结果完整
- **THEN** 导入报告成功，退出码为 0

#### Scenario: 字段被静默剥离时报错退出

- **WHEN** 导入过程中话题注册表或节点话题归属被校验层丢弃，落盘结果少于草案
- **THEN** 工具打印差异（字段名与两侧数值）并以非零退出码结束，同时提示重启 dev 服务

#### Scenario: 预览模式不做回读校验

- **WHEN** 使用预览（不写盘）模式运行导入工具
- **THEN** 只输出差异预览，跳过回读校验且不写盘

#### Scenario: 可显式关闭回读校验

- **WHEN** 用户显式传入关闭校验的开关
- **THEN** 工具在写盘后跳过回读比对，行为与加固前一致
