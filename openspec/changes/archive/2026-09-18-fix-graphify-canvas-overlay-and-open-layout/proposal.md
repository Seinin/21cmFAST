## Why

Graphify 画布当前有四处可观察的交互缺陷，让「看图谱」这件事变得不可靠：

1. 节点旁的浮层按钮（青色连线手柄、靛蓝展开/收起键）会越出画布、压在右侧详情面板上。
2. 打开阅读器（notes 阅读抽屉）时，这两个图标仍然透过半透明玻璃显影，像是浮在阅读器之上。
3. 展开/收起键「用过一次后就不可见」——而且**其他节点上的键也一并找不到**，导致收起一个分支后再也没有可点的恢复入口。
4. 打开图谱时节点排布是乱的：存档里是旧的力导向坐标，与默认「层级」布局对不上。

其中第 3 条同时是一处 spec 偏差：收起/展开在层级布局下走整树重排，而这条路径会**重新取景**，把视野缩放拉低并把画面整块换位，`refreshHandle` 的 `zoom < 0.6` 门槛随即把所有节点上的键一次性抹掉。主 spec `graphify-canvas-layout` 已写明「展开或收起一层后按所选布局重排**且不把视野跳走**」，当前实现没有满足它。

## What Changes

- **浮层不越界**：画布根容器建立层叠上下文并裁剪；两个按钮的位置按画布尺寸夹紧（右侧不够翻到节点左侧、垂直夹紧），焦点节点被移出视野时不绘制。
- **浮层不遮挡/不显影**：任一弹层或阅读抽屉打开期间，隐藏两个按钮与连线预览。
- **展开/收起键随焦点出现（悬浮可见）**：悬停、选中或被点击过（粘住）的节点才显示键——收起态是带 `+N` 的展开键，展开态是收起键；不再有绝对缩放门槛，缩放级别不影响键的出现。
- **键可反复使用**：去掉绝对缩放门槛（改为「焦点节点可见且其渲染位置在视野内」）；指针从节点移到键上不丢焦点；点过一次后键粘住并跟随节点，直到点空白、选中别的元素或弹层打开。
- **展开/收起不把视野跳走**：展开/收起触发的重排不再重新取景，改为保留当前缩放，并把被操作节点钉在原屏幕位置（键留在指针底下，可连续点按）。仅「打开图谱 / 切换布局 / 工具条重排 / 布局失败兜底」重新取景。
- **打开即整齐**：首次出现可见节点时按当前布局（默认「层级」）重排一次，不再沿用与当前布局不一致的历史坐标；工具条保留「层级」等布局选项，切换后立即重排。

不新增任何依赖（层级布局继续用 cytoscape 内置 `breadthfirst`），不改视觉风格、节点上限与展开规则，切换话题仍不改变节点位置。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `graphify-canvas-layout`: 「展开与收起后的重排」中「不把视野跳走」从「其它布局」扩展到所有布局——层级布局在重排整棵可见树的同时 MUST 保留当前缩放并让被操作节点保持原屏幕位置；新增/收紧浮层条目：浮层按钮 MUST 留在画布内、MUST NOT 绘制在弹层或阅读抽屉之上；「默认使用内置层级布局」补充「打开时 MUST 按当前布局重排一次，MUST NOT 沿用与当前布局不一致的历史坐标」。
- `graphify-canvas-budget`: 「逐层展开与收起」补充入口的可发现性与可重复性——带未展开下层的可见节点在悬停或选中时 MUST 显示展开入口（带未展开数量）且 MUST NOT 因缩放级别而消失；展开/收起入口 MUST 在同一位置可反复使用（MUST NOT 因一次操作或随后的重排而永久消失）。

## Impact

- 前端（`Graphify/`）：
  - `src/components/GraphCanvas.tsx`：浮层定位与可见性判定、指针宽限与点击粘住、话题 effect 与打开时布局的接线。
  - `src/graph/cytoscapeSetup.ts`：打开时的一次性布局标志；展开/收起重排的不取景路径与锚点屏幕位置补偿。
  - `src/graph/layout.ts`：模块级 `runLayout` 增加 `fit` 覆盖参数（默认行为不变）。
  - `src/App.tsx`：新增一处 `overlayOpen` 传参（不新增状态）。
- 数据：打开即重排会把 `data/graph.json` 的节点坐标回写为当前布局产出的坐标（预期行为，用户已确认；该目录未被 git 跟踪）。
- 不涉及：`/api/*` 契约、节点/连线编辑链路、`styles.ts` 节点样式、`MAX_VISIBLE_NODES` 上限、话题过滤语义。
- 工作量：小到中等，四个文件、无新增源文件与依赖。
