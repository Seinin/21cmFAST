## Context

动机见 proposal.md - Why。塑造方案的现状约束：

- 话题过滤当前是「两层可见性正交」：话题决定显示谁，折叠在显示范围内套用（`GraphRenderer.applyCollapseState()`）。
- 过滤不删元素，只切 `display` —— 节点坐标与折叠态因此天然跨话题保留，这是主 spec「切换话题保留位置与折叠状态」的实现基础，本次必须继续满足。
- 主树零边（落盘 `关系 0`），层级**只**由 `parent`（compound 容器）表达。
- cytoscape 3.34.3：复合容器的父子关系是一体的，把祖先容器设为 `display:none` **不能**保住其子节点可见。
- 前端无浏览器可用，验收依赖：真实模块复算（`node --experimental-strip-types` 直载 `src/lib/topics.ts`）、headless cytoscape 实测、`npm run build` 与 `npx eslint src scripts`。

## Goals / Non-Goals

**Goals:**

- 话题视图只出现本话题成员；父链越界的成员提升为顶层；话题内层级与折叠保持可用。
- 分组容器去描边、保留分组底色；折叠方块仍带描边与高亮。
- 切回不过滤视图后 compound 结构与切换前**完全一致**（来回切换幂等）。

**Non-Goals:**

- 不改布局算法、不引入「用边重建结构」（主树继续零边）。
- 不重构渲染器的既有职责划分，不引入缓存层或虚拟化。
- 不修改图数据文件（不重建、不重导）。
- 不做折叠深度可配置化，默认深度仍为 1。

## Decisions

**D1：可见集收敛为成员集，`context` 概念整体删除。**
「祖先降透明度」是当年为维持 compound 关系而付的视觉代价，与「只留本话题」互斥，二者不可能共存。备选是保留 `context` 但把不透明度降到 0，被否：隐形容器仍占据包围盒与 padding，会在成员之间留下肉眼可见的空隙、并干扰取景范围，折叠逻辑还得为它写特例。

**D2：越界祖先用 reparent 处理，而不是切 `display`。**
提升规则（纯函数，落在 `src/lib/topics.ts`）：每个成员 → 沿 `parent` 上溯找到的第一个**也属于本话题**的祖先；不存在则为 `null`（顶层）。实测依据：headless cytoscape 3.34.3 对 5 个元素跑完 grid 布局后，依次执行 `move({parent:null})` 与 `move({parent:'p'})`，三次坐标快照完全一致（`p=0/0 c=0/0 g=6/6 p2=0/0 c2=6/17`）——reparent 不移动模型坐标，且 `node.move({parent})` 本仓库 `sync()` 已在用。备选：扁平化（主树零边，扁平后毫无结构可看）、隐形容器（见 D1）。

**D3：渲染态一次性重算，按「结构提升 → 可见性隐藏 → 折叠」三步落态。**
顺序不可调换：先落结构再落可见性，才能避免出现「父已被隐藏而子仍挂着」的中转态。渲染器保存最近一次 `sync(graph)` 的图谱引用，`applyCollapseState()` 在无过滤时以真实父级为目标，因此清过滤/换话题都能还原，做到幂等。备选：在 `sync()` 里并联一份提升逻辑，被否——`sync()` 末尾已调用 `applyCollapseState()`，两处会互相覆盖。

**D4：取景只算可见元素。**
当前 `fit()` 是 `cy.fit(undefined, 80)`，会把隐藏元素的模型包围盒算进取景范围；新规则下隐藏的容器更多，必须改为只对可见节点集合取景，否则会出现「画面缩得比内容小很多」。

**D5：可见性指纹纳入结构。**
`topicVisibilityKey` 目前只含 `visibleIds`。提升后的父级可能变而可见集不变（两个话题成员相同、内部结构不同的情形），会把结构变化漏掉，导致画布不重套过滤。把提升映射一并纳入指纹。

**D6：分组外观由样式层单一改动承担。**
`node:parent` 去掉 `border-*`，标签从「贴在容器上沿之外」移进分组区域内部；`node.collapsed` 的描边与高亮保持不变——它是可点击实体，不是分组轮廓。

## Risks / Trade-offs

- [reparent 与 `sync()` 的父子对账互相覆盖] → 提升只放在 `applyCollapseState()`，靠其在 `sync()` 末尾执行取得权威；验证时专门构造「话题视图下触发一次 sync，提升仍生效」。
- [清过滤未还原会让 compound 结构永久错乱] → 无过滤时以真实父级为目标；验证「A → B → 全部」往返后 `parent` 与初始快照逐项相等。
- [`fit` 仍把隐藏元素算进取景] → 改为显式传入可见节点集合；若仍不符预期，回退为按可见包围盒手动计算 pan/zoom。
- [提升后顶层块数量与默认折叠深度不匹配] → 在落盘数据上复算：`engine` 期望 3 个顶层块（`nion:cond-mf:kernel` / `nion:single:mini` / `engine:root`），深度 1 收起其下一层。
- [生成器与文档口径漂移] → `build-nion-graph.mjs --topics` 与 `docs/DIRECTORY.md` §8.1 同步改，并用两侧数字交叉核对。
- [无浏览器，交互手感无法验收] → 浏览器内的点击/拖拽确认如实标注为待人工确认，不伪装成已验证。
