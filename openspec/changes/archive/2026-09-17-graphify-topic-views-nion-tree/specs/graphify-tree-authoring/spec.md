## Purpose

让知识图谱的自顶向下分解可被可靠地编写与生成：层级只由父子归属表达、结构上不可能成环，且生成过程对锚点与结构问题一律 fail-fast，并把未决内容归入专门话题而不是混入正题。

## ADDED Requirements

### Requirement: 大纲 v2 以扁平节点表达层级

生成器 SHALL 从「话题注册表 + 扁平节点列表」形式的大纲生成图谱草案；每个节点通过 `parent` 字段且仅通过该字段表达层级，`parent` 为空表示顶层节点。生成器 MUST 拒绝 `parent` 指向不存在节点的输入。

#### Scenario: 合法大纲生成草案

- **WHEN** 运行生成器并提供一份含话题注册表与扁平节点列表的大纲
- **THEN** 生成图谱草案文件，且草案中每个节点的父子归属与大纲一致

#### Scenario: 悬空父节点被拒绝

- **WHEN** 大纲中某节点的 `parent` 指向不存在的 id
- **THEN** 生成器报错退出并指出该节点与其父 id，不产出草案

### Requirement: 层级为单父多叉树且禁止成环

生成器 MUST 校验父子关系构成森林：任一节点至多一个父节点，且沿 `parent` 链向上不会回到自身（无环）。存在环或自指时 MUST 报错退出，不得静默降级。

#### Scenario: 环被检测并拒绝

- **WHEN** 大纲中存在 A → B → C → A 的父子链
- **THEN** 生成器报错退出并列出构成环的节点 id

#### Scenario: 自指被拒绝

- **WHEN** 某节点的 `parent` 等于自身
- **THEN** 生成器报错退出

### Requirement: 深度与规模约束

生成器 MUST 校验每个话题内从该话题顶层算起的层级深度不超过 4 层，并输出节点总数与各话题规模统计供人工核对。涉及 Nion 积分的主话题根节点 MUST 只有两个直接子节点。

#### Scenario: 超深树被拒绝

- **WHEN** 某话题内存在第 5 层的节点
- **THEN** 生成器报错退出并指出该节点及其深度

#### Scenario: 主话题根只有两个子节点

- **WHEN** 生成 Nion 积分主话题
- **THEN** 报告显示根节点的直接子节点数量为 2

### Requirement: 锚点零失配

大纲中的引用 SHOULD 只写标题文本或正则表达式；生成器 MUST 用文档标题索引回填真实锚点，并在解析失败或一个标题文本匹配到多个标题（锚点歧义）时报错退出。生成器 MUST NOT 接受手写的锚点 slug。

#### Scenario: 引用解析失败时报错

- **WHEN** 某引用写的是文档中不存在的标题文本
- **THEN** 生成器报错退出并指出该引用所在节点

#### Scenario: 锚点歧义时报错

- **WHEN** 某引用的标题文本在同一文档中匹配到多个标题
- **THEN** 生成器报错退出并要求改写为正则

### Requirement: 主话题不使用语义边

承载 Nion 积分分解的主话题 MUST NOT 使用关系边（仅有父子归属），以保证结构上不含环；原有跨分支语义 SHALL 写入节点摘要文字。图谱数据模型与画布 MUST 继续支持边，以供其它视图使用。

#### Scenario: 主话题零边

- **WHEN** 生成并导入 Nion 积分主话题
- **THEN** 该主题视图不含任何关系边，且画布正常渲染

#### Scenario: 其它视图仍可使用边

- **WHEN** 导入一份含关系边的图谱（如全库骨架视图）
- **THEN** 边正常显示并可选中

### Requirement: 逐层收纳与默认折叠深度

任意层级含子节点的容器 MUST 可被收起/展开；收起时其全部后代 MUST 折叠为一个方块并显示「名称 · 后代数量」。首次加载图谱时默认折叠深度 MUST 为 1（可见「根 + 两个乘子」共 3 个方块）；「全部收起」按钮 MUST 保持「仅保留顶层节点」的语义。

#### Scenario: 默认打开呈三个方块

- **WHEN** 首次打开 Nion 积分主话题
- **THEN** 画布上可见根节点与它的两个子节点，共 3 个方块

#### Scenario: 收起任意深度容器

- **WHEN** 双击第 3 层的容器节点
- **THEN** 该容器及其全部后代折叠为单个方块，方块标题含后代数量

#### Scenario: 全部收起仅留顶层

- **WHEN** 点击「全部收起」
- **THEN** 画布上只剩顶层节点

### Requirement: 未决内容归入话题而非问题节点

未决口径 MUST NOT 以「问题」类型节点混入正题；它们 SHALL 归入专门的话题（该话题拥有自己的顶层根节点），其节点类型按其在公式中的角色取概念/方法/结论。

#### Scenario: 主话题不含问题节点

- **WHEN** 检查 Nion 积分主话题的节点类型分布
- **THEN** 其中不含「问题」类型节点

#### Scenario: 待确认话题可独立打开

- **WHEN** 切换到「待确认」话题
- **THEN** 画布显示该话题的根节点及其未决条目，与主话题内容互不混入
