## MODIFIED Requirements

### Requirement: 预览按段连续浏览全文

预览 SHALL 以**段**为单位读取源码：每段 MUST ≤300 行，段与段之间行号 MUST 连续、不重叠、不漏行。当已加载内容距顶部或距底部 200 像素以内、且该方向存在相邻段时，系统 SHALL 自动加载相邻段并并入已加载内容，MUST NOT 要求用户执行额外操作才能继续读。向上续段（前插）MUST 保持当前阅读位置不跳动。界面 SHALL 标注当前已加载范围与文件总行数。

段 SHALL 只作为**读取与传输**单位：显示层 SHALL 把已加载的**首尾相接**的段合并为一个代码块并只对其做一次语法分析，MUST NOT 让跨行的字符串或注释（文档字符串、块注释、模板串）在段接缝处被切断。合并后每个可见行的行号 MUST 仍等于它在文件中的真实行号，且同一行号 MUST NOT 出现两次。

#### Scenario: 打开即见到引用行所在的那一段

- **WHEN** 用户从某个实体的源码引用打开预览
- **THEN** 抽屉 SHALL 显示包含被引用行的那一段（≤300 行），并标明该段范围与文件总行数

#### Scenario: 滚到边界自动续段

- **WHEN** 已加载内容距底部不足 200 像素且其后仍有未加载的行，或距顶部不足 200 像素且其前仍有未加载的行
- **THEN** 系统 SHALL 自动加载相邻段：向后直接追加，向前插入到已加载内容之前，且两种情况下行号都接续、不重复

#### Scenario: 向上续段时阅读位置不跳动

- **WHEN** 前插上一段（向上续段）完成
- **THEN** 插入前正在看的那一行 MUST 仍停留在原屏幕位置

#### Scenario: 分段边界不重不漏

- **WHEN** 从引用行所在段逐段读到文件末尾
- **THEN** 所有已加载段的行号集合 MUST 恰好覆盖 1..N（不重复、无空洞），N 为文件总行数

#### Scenario: 连续区间合并成一个代码块

- **WHEN** 已加载的多个段首尾相接（例如 1–300、301–600、601–N）
- **THEN** 显示层 SHALL 把它们渲染为一个代码块并只做一次语法分析；每个可见行仍带真实文件行号，且行号集合不重复

#### Scenario: 跳转造成的空洞分块显示

- **WHEN** 已加载的段互不相接（例如跳到文件头后得到 1–300 与 601–N）
- **THEN** 显示层 SHALL 分成多个代码块，MUST NOT 把两段硬拼成一次分析

#### Scenario: 跨段接缝不切断跨行构造

- **WHEN** 某个跨行构造（文档字符串 / 块注释 / 模板串）横跨两个已加载段的接缝
- **THEN** 该构造覆盖到的每一行 MUST 仍按其本来语义着色，接缝之后 MUST NOT 出现整片变色

## ADDED Requirements

### Requirement: 从跨行构造内部开始的窗口由一行词法上下文摆正

当一段窗口的起点落在跨行的字符串或注释**内部**时，服务端 SHALL 随该窗口返回一行**词法前缀**：开启那个构造的那一行的原文与它的行号；窗口起点不在任何跨行构造内部时 MUST NOT 返回前缀（MUST NOT 为此付出扫描之外的开销）。前端 SHALL 把前缀文本拼在待分析文本之前，且 MUST NOT 把它作为可见内容渲染出来——它 MUST NOT 造成行号跳号，也 MUST NOT 与已加载的上一段重复同一行。

构造的识别 SHALL 按语言家族进行（`#` / `//` / `!` 行注释、块注释、三引号、反引号模板串、以孤立反斜杠续行的字符串），注释或字符串**内部**出现的标记 MUST NOT 被当作构造起点。行注释到行尾即结束，MUST NOT 跨行。

#### Scenario: 窗口起点在构造内部时给出前缀

- **WHEN** 请求的窗口起点落在某个跨行构造内部（如文档字符串从第 590 行开到第 639 行，而窗口从第 601 行开始）
- **THEN** 返回值 SHALL 携带 `lexPrefix`，其 `start` 为开启该构造的行号（590），`text` 为那一行的原文

#### Scenario: 窗口起点不在构造内部时不给前缀

- **WHEN** 窗口起点不在任何跨行构造内部（含起点恰是构造的开启行、或恰是闭引号行的下一行）
- **THEN** `lexPrefix` MUST 为 `null`

#### Scenario: 前缀不显示且不改变行号

- **WHEN** 前端渲染一个带词法前缀的代码块
- **THEN** 前缀那一行 MUST 被隐藏且 MUST NOT 参与行号标注；其余可见行的行号 MUST 等于它们各自的真实文件行号

#### Scenario: 字符串或注释内部的标记不算构造起点

- **WHEN** 文件里出现 `char *p = "/*";` 这样的内容
- **THEN** 它 MUST NOT 被识别为块注释的开始，其后各行 MUST 仍按代码处理

#### Scenario: 各类跨行构造同等对待

- **WHEN** 窗口起点落在 Python / TOML 的三引号字符串、C / C++ / CUDA / CSS 的块注释、或 JS / TS 的模板串内部
- **THEN** 两种取法（`highlight` 与 `mode=range`）SHALL 都给出对应的词法前缀
