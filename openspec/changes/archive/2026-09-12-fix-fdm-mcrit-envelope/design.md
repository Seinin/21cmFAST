## Context

动机与数值证据见 `proposal.md - Why`。此处只记录决定「怎么修」的现状与约束：

- **eq.(1) 的真实结构**：`f(u) = η_p(u) · (u/r)^γ` 在 `u > 0` 上严格单调递增（两个正递增函数之积），从 `0` 升到 `η_p(1) · r^{-γ} > 1`，故根**唯一且有限**。`γ ≤ 0` 时 `f(u) → η_p(u) ≤ 1`，除非 `γ=0` 且 `u → ∞`，方程退化。
- **`m_k` 族的真实结构**：`m_k = [(a)^k + (b)^k]^(1/k)`（`a = m_crit^CDM`、`b = M_sol`）在 `k` 上**单调递减**，`k → 0+` 时 `→ +∞`，`k → +∞` 时 `→ max(a,b)`（下确界，取不到）。所以 `k ∈ [1, ∞]` 只覆盖 `[max(a,b), a+b]` 这一窄带。
- **代码现状**：`m_crit^FDM` 的 ansatz **未进入 C 端**。MCG turnover 在 `HaloBox.c:495`（及 `:744`）、`scaling_relations.c:87`、`IonisationBox.c:430` 处均为 `lyman_werner_threshold(z, J21, vcb)`；FDM 仅以 `dndm_FDM`（`fdm.c:54`，参数 `M0`、`HMF_FINDEX`）作为 HMF 压制出现。因此本次不存在「改 C 公式」的问题。
- **下游注入接口已存在**：`get_global_Nion_z` 等 C 积分允许外部传入 `log10_turnovers_mcg`，即 MCG 通道的 `Mturn`（对应 `hmf.c` 中 `exp(-mturn_mcg/M_h)` 截断），故可零 C 改动地测量下游响应。
- **已有驱动**：`train/_sens_mcrit_kpg.py`（本次新增，已跑通；残差 0，`k_eff` 回代 roundtrip = 1.000000）。

## Goals / Non-Goals

**Goals:**

- 让 `m_crit^FDM` 的中心值由 eq.(1) 自洽决定，并把「k 不可自由取值」这一事实落实为可复算的检查
- 给出 `k_eff` 的参数依赖与偏差因子，量化「用 `k=2` 会低估多少」
- 修正文档 §5.6/§5.8/§5.12 中与自洽解冲突的结论，并留下数值验证节

**Non-Goals:**

- **不**把 `m_crit^FDM` 实现进 C 端（当前 MCG turnover 仍是 LW 阈值；加入 FDM 项会改变模拟输出，属独立物理改动，另开 change）
- **不**重新校准 `η(x)` 形状、`γ`、`p`、`M_sol` 前置系数（需 §10.4 的 ENZO/AxiREPO 模拟）
- **不**声称 `m_exact` 是最终真值——它只是 eq.(1) 在给定假设下的解
- **不**删除 `m_k` 族的代码与图，只改变它的定位（对照而非中心值）

## Decisions

### 决策 1：中心值改为 eq.(1) 的数值解，`m_k` 族降级为对照

用 `brentq` 在 log 空间求解，基准值取代 `sqrt(a²+b²)`。

*备选*：保留闭式形式，只把 `k` 从 2 调到某个拟合值。否决——`k ≥ 1` 时该族无法表示精确解（见 proposal 表），把 `k` 当自由参数正是本次要消除的错误自由度；且 `k` 无独立物理含义。

*代价*：中心值不再有闭式，需要在脚本中引入求根依赖（`scipy.optimize.brentq`，已是项目依赖）。

### 决策 2：求根在 log 空间做，并用残差断言兜底

残差函数写成 `f(u) = expm1(log η_p(u) + γ·(ln u − ln r))`，配合等比倍增上界（`u = 1, 2, 4, ...` 直到 `f > 0`）。`η_p` 用 `logaddexp` 形式避免大 `u` 溢出；`m_k` 的幂也用 `min(..., 700)` 截断以防 `exp` 溢出。

*备选*：直接线性空间迭代。否决——`r` 可跨 6 个数量级，`u` 可达 `1e14`，线性形式在 `p`、`γ` 组合下不稳定。

### 决策 3：反解 `k_eff` 必须区分「低于下确界」与「超出搜索上界」

族单调递减，故有效区间是 `[max(a,b), m(k_min)]`。哨兵值定义为：`nan` = 精确解低于 `max(m_crit^CDM, M_sol)`；负值 = 精确解超过 `m(k_min)`，即 `k_eff < k_min`。

*理由*：静默把边界值当结果会制造假样本——本次实现中就因此一度让所有样本返回 `k_eff = 1e-3`，掩盖了真实分布。这类「边界即答案」的错误必须在接口层面排除，而不是靠调用方小心。

### 决策 4：下游响应不重新实现，注入 21cmFAST 自身的 Mturn

把变体 `m_crit` 作为 MCG 通道的 `log10Mturns` 传给 C 积分，并**逐 z 调用**以保证每次调用的 scaling constants 使用当点 `z`（批量调用会用单一 `z` 算常数，导致曲线失真）。

*备选*：自己在 Python 里写 `exp(-Mturn/M)` 截断积分。否决——无法反映 `get_global_Nion_z` 内部的 HMF、SFR、逃逸分数等全部处理，结论不可归因。

### 决策 5：文档改法——保留推导但标注前提失败

§5.6 的推导与 `k=2` 的提出过程保留（有史料价值），但加显著标注：其误差估计 `R^{γ/(p+γ)}` 依赖 `m_FDM/M_sol ≫ 1`，而自洽解给出的比值在 1–4，故 `126^0.09 ≈ 1.6×` 不成立，实际偏差 1.1–3.9×（中心参数 `(p,γ)=(1,0.1)` 下）。§5.8 的「`k ∈ [1,∞]` 为系统误差包络」改为「须在 `k_eff` 实际分布上取值，全网格样本 `k_eff` 中位 0.39、16–84% 分位 `[0.27, 0.57]`、100% 小于 1」。

*备选*：删除 §5.6 的推导。否决——推导展示的对称性论证仍有效，失败的只是「用该族做包络」这一步。

### 决策 6：§5.13 主图必须把「族内窄」与「解在带外」压在同一张图里

采用三面板 `testplots/fdm_mcrit_k_insensitivity.png`：

| 面板 | 内容 | 一眼可读的信息 |
|---|---|---|
| (a) | 横轴 `z`，纵轴 `m/m(k=∞)`；`k=1/1.5/2/5` 四条线 + eq.(1) 精确解一条线 | 四条线挤成一条 `1.00–1.15` 的窄带（族内 `k` 无自由度），精确解孤悬在 `1.3–3.9` |
| (b) | `(m22, z)` 平面填 `R_{1∞} = 1 + min/max`，白=`1.00`、深=`2.00`，附 `R=1.1` 等值线 | 绝大部分观测量区间 `≤1.1`；且该量有闭式，**不依赖任何数值求根** |
| (c) | `k_eff` vs `γ` 散点 + `k=1` / `k=2` 参考线 | 全部点落在 `k=1` 之下，`k=2` 作为中心值无依据 |

*备选 1*：只画 `m_crit(z)` 的绝对曲线族。否决——log 轴上几条曲线「看起来重叠」无法量化重叠程度，也看不出与解的距离；比值图把两个信息压到同一纵轴，可直接读数。

*备选 2*：画 `|m_exact − m_k|` 差值。否决——差值随 `(m22, z)` 跨数量级，量级差异会主导视觉，弱化「族内几乎无差异」这一要点。

*备选 3*：拆成两张图（窄带一张、解在外一张）。否决——读者极可能只看其中一张，从而得出与结论相反的印象（见 proposal 的同名风险）。必须**同版面强制成对**，并在图题写明「带窄 ≠ 可用，正因无自由度才无法伸展到解」。

图文件落在 `testplots/`（与 `scripts/compare_fdm_mcrit.py` 的 `FIG_DIR` 一致），由 §5.13 以 `../testplots/...` 引用。

*备选*：写入 `docs/figures/`。否决——该目录是上游 Sphinx 图库（324 个 png），混入研究用图会造成归属混淆。

## Risks / Trade-offs

- **[风险] `η(x)`、`γ`、`p` 本身未校准** → 缓解：报告与文档均标注 `m_exact` 是「eq.(1) 的解」而非「真值」；校准任务保留在 §10.4
- **[风险] 文档内多处交叉引用 §5.6/§5.8 的旧结论** → 缓解：实施时全仓库检索 `k=2`、`包络`、`sqrt(`、§5.8 等锚点，逐处更新
- **[风险] 数值解在极端 `r`（`r → 0` 或 `r ≫ 1`）下精度退化** → 缓解：对每点做残差断言（`|LHS−1| ≤ 1e-9`）与 `k_eff` 回代校验（相对误差 ≤ 1e-6），不通过即报错而非静默
- **[权衡] 本次不改 C 端** → 模拟输出仍不含 FDM `m_crit`；以「现状缺口」小节显式记录，避免误读为「模拟已包含该效应」
- **[权衡] `k` 系列曲线保留** → 图与报告中仍会出现 `k=1/1.5/2/5/inf`，需在标题/图例中标明它们是「对照」，避免读者重新把它当中心值
- **[风险] 主图被误读为「`k` 不重要 → 该族可用」** → 缓解：面板 (a) 强制同轴呈现族内四条线与精确解，图题写明「带窄源于族被 `max(a,b)` 钉死，正因无自由度才无法伸展到 eq.(1) 的解」；面板 (b) 用解析式而非数值填色，避免引入额外不确定度
- **[风险] 面板 (b) 的 `R_{1∞}` 只依赖 `(m_crit^CDM, M_sol)`，不含 `γ`/`p`** → 缓解：在图题注明它是「族的几何展宽」而非「模型不确定度」，后者才是面板 (a)/(c) 与 §5.13 表格的内容
