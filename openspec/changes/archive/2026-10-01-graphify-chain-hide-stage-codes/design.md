# Design

## D1 编号留在数据，名字去掉编号

内部编号（`L0/L1`、`M1…M10`、`S04/S07`…）有两类用途：

| 用途 | 谁在用 | 本次处置 |
| --- | --- | --- |
| 把对象钉到代码上（这块 = 哪个 `Compute*` 步、这个量算在哪段代码里） | 维护者、自检 | **保留**：`stage` / `codeHints` / `codeAnchor` / `algorithms` 字段不动，自检的逐条对拍断言不动 |
| 当名字用（框上的字、成员明细右列、命中说明、引用落点、文档标题） | 读这一页的人 | **去掉**：编号不再进任何界面文案 |

判据是"**这句话是给读者看的，还是给核对用的**"。前者去编号，后者留编号。

## D2 为什么改名字本身，而不是在显示层掩码

显示层掩码（渲染前把 `M8 ` 前缀裁掉）看着更省事，但它会造出**两个名字**：数据里的 `M8 气体热与自旋温度` 与界面上的 `气体热与自旋温度`。代价有三：

1. **锚点对不上**：笔记引用的锚点是"小节标题的 slug"，而标题就是标签本身（`build-physics-chain.mjs:415-419`）。掩码只改显示不改锚点，卡片上印的短落点就与文档里真实的小节标题不是同一个字符串。
2. **散文无法掩码**：真源散文里是"下游 M4/M8/M9/M10 都拿它当参数"这种**句子中的编号**，正则替换会产出"下游 晕目录与质量函数/气体热与自旋温度…"这种没有引号、读不顺的句子。散文是**人写的**，就该由人改写。
3. **两份真源**：掩码表本身要维护（哪个编号对应哪个名字），而这份映射在真源里已经存在（块的 `label`）——多一份映射就是多一处会漂移的口径。

所以：**名字在真源与生成器里就去掉编号**，界面、文档、锚点、检索四条线自动一致，没有别名。

## D3 块名与文件名

- 块名 = 去掉前缀的 `label`：`气体热与自旋温度`、`晕目录与质量函数`…（`order` 字段仍记主序位次，一级的先后不受影响）。
- 骨架文档文件名 = 块的 id 去掉 `block:` 前缀 + `.md`：`block:thermal` → `thermal.md`。这条规则可写进 README、也可被自检核对（`noteDoc` 必须等于 `physics-chain/modules/${id.slice(6)}.md`），改名以后不再出现"文件名里的编号与块名不一致"。
- 步骤小节标题 = 步骤名（`UpdateXraySourceBox`）。生成物里实测 21 个步骤，去码后**同一份文档内没有重名**（不同块之间也不重名），锚点不会互相盖掉。

## D4 成员明细右列退场

块「成员明细」的右列印的是成员的 `stage`（`S14`）。它不是"点不开的摘要"那种展示项，而是一列**代码坐标**——与块名 / 成员名并排时，读者会以为它是这一列的一部分。撤列，`stage` 字段照旧（检索面仍认它、自检仍对拍）。

## D5 自检怎么守住这件事

一条断言管一类出口，全部**在生成物与真源上重算**，不靠肉眼：

- 标签面：`graph/nodes[].label` 与 `blocks.items[].label` 里没有内部编号形状（`^[MLS]\d` 开头或词边界处出现）；
- 落点面：每条笔记引用的 `docId` 与 `anchor` 不含编号形状；
- 散文面：块注 / 过程面注 / 边注 / 兜底注的字符串不含编号形状；
- 命中说明面：`searchChain` 的 `detail` 拼装不再读 `node.stage`（反面断言：源码里不许把它拼回去）；
- 骨架面：骨架文档的标题（`#` 与 `###`）不含编号形状——这条与"标题就是标签"的对拍断言互为补充。

反面断言都要真跑一次演练（改名 / 塞回一个编号 → 当场失败 → 复原）。

## D6 风险与不做的事

- **不改 atlas 册子**（`docs/notes/atlas/**`）：那里的 `S14.3.1` 是代码拓扑账本自己的坐标，页面上也不呈现它。
- **不改 `algorithms` 注册表里的 `how/when/where`**：没有界面出口（检查器不读它），它是维护者的账。
- **不动画布页**：改名走真源 + 生成器，`Inspector` 的 `inline` 分支（画布页引用可增删）一个字不动。
- **与未归档的 `graphify-chain-leaf-refs` 的关系**：它 6.3 保留过「命中说明里的『代码 S14』」，本变更撤销该展示；它的规格 delta 里钉的落点是**代码**引用的形状（`SpinTemperatureBox.c` + 行区间），不含模块码，故不冲突。它 3.1/3.2 里写的骨架文档名（`M8-*.md`）是当时的记录，本变更改名后以本变更的 tasks 为准。
- **改名后要一起改的引用**：`docs/DIRECTORY.md`、`docs/notes/physics-chain/README.md`、`docs/notes/graphify/G4-物理链.md` 的指向与示例；`docs/notes/physics-chain/README.md` 里"节点符号 = atlas 阶段编号"那段口径要改成"名字不含编号、编号只在数据里"。
