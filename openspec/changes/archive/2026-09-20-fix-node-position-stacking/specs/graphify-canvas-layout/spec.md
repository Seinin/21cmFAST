## MODIFIED Requirements

### Requirement: 打开图谱时的取景覆盖全部可见节点及其标签

打开图谱（含刷新页面）以及用户显式触发「取景」「重排」时，默认视角 MUST 把全部可见节点及其名称标签一并纳入取景范围：取景 MUST 按包含标签的包围盒计算并留出边距，使所有可见节点的名称完整落在画布矩形内，MUST NOT 出现节点名称被切在画布外或被画布边缘裁掉的情形。取景 MUST 仍只考虑可见元素，被隐藏的节点 MUST NOT 影响取景范围。该取景 MUST NOT 破坏既有约束：展开与收起后的重排 MUST NOT 重新取景、MUST NOT 改变当前缩放与视口位置；改变话题开关集合只在「新揭示的节点尚未排布过」时才允许先补一次重排（补排自带一次取景），其余情况 MUST 只取景不重排。

#### Scenario: 打开即全部节点可见

- **WHEN** 打开图谱（含刷新页面）且当前话题下有可见节点
- **THEN** 全部可见节点连同它们的名称都出现在画布内，边缘节点的名称不被画布边界裁掉

#### Scenario: 标签宽度计入取景范围

- **WHEN** 某个边缘节点的名称比它的节点矩形更宽
- **THEN** 取景把名称的宽度一并计入，该名称完整可见，节点本身也不会被压到画布边角

#### Scenario: 隐藏元素不影响取景

- **WHEN** 画布上存在因未展开或话题过滤而隐藏的节点，随后触发取景
- **THEN** 适配范围只由可见节点决定，画面不因隐藏节点而过度缩小

#### Scenario: 展开收起后不重新取景

- **WHEN** 在可见全部节点的默认视角下展开或收起某一层
- **THEN** 缩放级别与视口位置保持不变，不发生重新取景

#### Scenario: 切换话题通常不重排

- **WHEN** 关闭或开启任意话题，且新揭示的节点此前都已排布过
- **THEN** 节点坐标不变，只有视野对新的可见集重新适配

## ADDED Requirements

### Requirement: 节点坐标必须是真实排布结果

节点坐标 MUST 只来源于一次真实排布（布局完成）或一次用户拖动，MUST NOT 由占位坐标填充。图形层在回存坐标时 MUST 只回存**当前可见且确实被排布过**的节点；隐藏的、从未排布过的节点 MUST NOT 被写入坐标（其既有坐标保持不变）。加载图谱时，若「多个节点共享同一坐标」达到占位判定阈值（同一坐标被 3 个及以上节点占用），这些节点 MUST 被视为尚未排布：其存储坐标 MUST 被忽略并交由布局重新排布，MUST NOT 原样显示成一堆重叠节点。任一时刻画布上可见的节点 MUST 两两不共享同一坐标。

#### Scenario: 打开被占位坐标污染的数据

- **WHEN** 打开一份图谱，其中一批节点的存储坐标完全相同（例如都停在默认原点）
- **THEN** 这批节点被视为未排布，开场布局把它们排开；画布上不出现一堆完全重叠、标签互相压住且无法分辨的节点

#### Scenario: 未排布的节点不被回存

- **WHEN** 一次布局只覆盖了当前可见的节点
- **THEN** 未可见 / 未参与排布的节点不会被写入坐标，其原有坐标保持不变；随后再次打开图谱时，这些节点仍被当作未排布并参与排布

#### Scenario: 可见节点坐标两两不同

- **WHEN** 在一份含隐藏分支的图谱上完成开场排布，并逐层展开到可见上限
- **THEN** 任一时刻可见的节点坐标两两不同，不存在两个节点完全重合

#### Scenario: 拖动过的节点保留其坐标

- **WHEN** 用户把某个节点拖到新位置，随后保存并重新打开图谱
- **THEN** 该节点仍在其被拖动到的位置（用户拖动被视作一次真实的坐标来源）
