## ADDED Requirements

### Requirement: 左栏并排两个检索面

物理链页左栏 SHALL 提供两个并排的检索面：「参数」与「天体物理过程」，以页签切换，默认打开「参数」面且行为与现状一致。两个面的词条 MUST 都取自本页生成物（`physics-chain.json`），视图 MUST NOT 写死任一面的人手名单。过程词条 MUST 给出三条信息：过程名、它下辖的量数、它用到的论文出处数（论文出处口径与本页「文献」那一路同源）。某一面为空时 MUST 写明原因，MUST NOT 渲染成空面板。

左栏 MUST NOT 再出现跨分组的「代码类」总计数徽标（各分组头上的条数不受影响）。切换页签 MUST NOT 改动画布选中与画布数据，MUST NOT 丢弃另一面的词条数据，也 MUST NOT 清空画布页状态。

#### Scenario: 默认打开参数面且没有代码类总计数

- **WHEN** 打开物理链页、检索框为空
- **THEN** 左栏显示「参数」面（参数词条按代码类名分组、各组带条数），且**不出现**「N 个代码类」这类跨分组总计数徽标

#### Scenario: 切到过程面

- **WHEN** 点击左栏的「天体物理过程」页签
- **THEN** 词条换成过程清单，每行写明过程名、它下辖的量数与它用到的论文出处数；参数面收起但数据未被丢弃

#### Scenario: 来回切页签不改选中

- **WHEN** 在画布上选中一个量，然后切到过程面再切回参数面
- **THEN** 画布选中对象与画布数据与切换前一致

#### Scenario: 名单改了视图不用改

- **WHEN** 在真源里增删一个过程并重新生成
- **THEN** 左栏过程面按新名单渲染，页面代码无需改动

### Requirement: 天体物理过程清单的单一真源

过程清单 MUST 只有一份声明：真源 `docs/notes/physics-chain/chain.json` 的 `processes`（一条 = 一个过程：名字 + 成员 id + 主块 + 它对应的论文拟合律 / 公式出处），生成器 MUST 原样烘进生成物。

过程名 MUST 是「按论文等式打包」的物理过程（如 `Lyα 耦合`、`气体热史`、`自旋温度`），MUST NOT 与一级的代码模块块（`M1`…`M10`）混为一谈，MUST NOT 再引入一套圆圈数字编号（同屏已有三套 `⓪`…`⑨`）。过程面 MUST NOT 用 `order` / 档位做筛选或排序。

自检 MUST 独立重算并断言：每个量与驱动量**恰好**属于一个过程或一条带（不重不漏），且每个成员 id 在真源里存在。不满足时 MUST 失败并列出漏掉、重复或悬空的 id。

#### Scenario: 不重不漏

- **WHEN** 运行物理链自检
- **THEN** 过程与带的成员并集恰好等于生成物里的全部量 + 驱动量；多一个、少一个或有一个成员同时出现在两条过程里都判失败，并列出相关 id

#### Scenario: 成员悬空被抓

- **WHEN** 在真源 `processes` 里写一个不存在的成员 id 并重新生成
- **THEN** 自检失败并指出该 id

#### Scenario: 名字不是一级块名

- **WHEN** 查看过程面词条
- **THEN** 出现的是过程名（如 `Lyα 耦合`），不出现 `M8`、「气体热与自旋温度」这类代码模块块名

#### Scenario: 过程面不按档位筛人

- **WHEN** 改动某个块或成员的 `order` 并重新生成
- **THEN** 过程面的词条集合、顺序与筛选结果都不变

### Requirement: 过程与参数互为矩阵

过程面与参数面 MUST 互为反查。在过程面点中一个过程，MUST 在本页定位到它的主块并选中（复用既有的定位与选中），并点亮参数面里与它相关的参数；在参数面点中一个参数，MUST 点亮过程面里读了它的过程。反查口径 MUST 复用既有的「参数 × 节点矩阵」，MUST NOT 另造一份参数归属表。两侧计数 MUST 由生成物算出，MUST NOT 写死。某个过程与任何参数都无关系时，MUST 显式写明「无」，MUST NOT 静默呈现为空。

#### Scenario: 点过程定位并点亮参数

- **WHEN** 在过程面点中 `Lyα 耦合`
- **THEN** 画布定位到它的主块 `M8 气体热与自旋温度` 并选中该块，参数面里与它的成员量（`jalpha` / `xalpha`）有关系的参数被点亮；一个都没有时写明「无」

#### Scenario: 点参数点亮过程

- **WHEN** 在参数面点中一个参数 `P`
- **THEN** 过程面里成员量读了 `P` 的那些过程被点亮

#### Scenario: 反查口径同源

- **WHEN** 运行物理链自检
- **THEN** 由过程反查出的参数集合，与「参数 × 节点矩阵」按同一成员量算出的结果逐条一致（没有第二份归属表）

### Requirement: 兜底小节承载带与未归属的量

过程面 MUST 用一个常驻、默认收起的小节承载**不是过程**的两条「带」（`环境与给定`、`观测量`）与旧划分覆盖不到的量。小节标题 MUST 写明它收纳什么、有几项、以及它们不是过程。展开后这些项 MUST 可选中、可定位到它的块，与过程词条走同一套交互；默认状态下它们 MUST NOT 混在过程词条之间。

#### Scenario: 小节写明内容与数量

- **WHEN** 查看过程面的收起小节（收起状态）
- **THEN** 标题写明它是「带与未归属的量」、给出项数，并注明它们不是过程

#### Scenario: 一键展开可用

- **WHEN** 点击展开
- **THEN** 两条带与未归属的量出现在词条里，可选中并定位到各自的块；再点一次恢复收起

#### Scenario: 不与过程混排

- **WHEN** 过程面处于默认状态
- **THEN** 带与未归属的量不出现在过程词条之中，只出现在兜底小节里
