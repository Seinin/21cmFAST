## Why

物理链页（第三页）首屏已经"基本只讲物理"，但**这件事拦不住**：生成器自己把 S04 标成「旁路 · 不在主链上」，却仍给它建一个一级框（现在一级 7 个框里就有它）；而自检那条"一级只有 N 个框"实际是 `框数 == 阶段数` 的**恒等式**（框就是从阶段数来的），所以"一级混进旁路 / 工程"没有任何断言能证伪。同时本页还有三处口径缺失：工程侧只能从检查器点话题才展开（`implCount` 算出来却从未使用）、顶栏搜索框在物理链页搜的是**画布那份数据**并把结果选进**画布选区**、状态条报的是画布口径（画布节点数 / 缩放 / 保存状态）。先把分层纪律定成规格与可证伪断言，再补这三处，否则后面每加一层都会重新渗回去。

## What Changes

- 一级（根画布）只放**物理过程主链**的框：旁路 / 诊断出口阶段（S04，生成器已判定"不在主链上"）不再占一级，与工程实现一起收进下方**默认收起**的「旁路与实现细节」条。**BREAKING**（首屏可见集与生成物里框的分层标签变化）。
- 分层判据成为**单一真源**：新增 `Graphify/scripts/lib/physicsStages.mjs` 声明"哪些阶段属于物理主链一级"，生成器与自检 import 同一份；生成物给每个过程框写入分层标签，视图只按标签渲染、不写死阶段名单。
- 自检把恒等式换成**可证伪断言**：一级框集合 == 物理阶段口径；旁路框不得出现在一级；工程节点必带 `topic:impl`、非工程节点不得携带。
- 工程侧**一键可达**：页面自带一条折叠条，写明数量与"不属于物理链"，一键展开 / 收起，不再只依赖检查器里点话题。
- **本页检索**：按本页生成物检索（参数 / 物理量 / 过程名 / 论文），命中旁路或工程侧时标注来源并在选中后自动展开折叠条；不再改动画布 store 的选区。
- 状态条在物理链页报**本页口径**（物理过程数 / 子过程数 / 参数数 / 文献数 / 当前打开对象），不报画布口径。
