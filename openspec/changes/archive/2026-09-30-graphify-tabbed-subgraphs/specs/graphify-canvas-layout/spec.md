## REMOVED Requirements

### Requirement: 展开与收起后的重排

**Reason**: 原地展开/收起被「子图标签页」导航取代（见 graphify-subgraph-tabs），不存在同屏展开一层后需要重排的情形。
**Migration**: 重排语义由「标签页内按层整理」承接，装饰框随子节点布局自动合围。

## ADDED Requirements

### Requirement: 布局方式按标签页独立

布局方式（手动摆放 / 力导向 / 同心圆 / 层级 / 环形 / 网格）MUST 按标签页各自保存：

- 在当前标签页切换布局方式 MUST 只重排该标签页的可见节点，MUST NOT 影响主图或其它子图的节点坐标；
- 隐藏中的标签页 MUST NOT 因布局切换或数据同步而被重排（只记下布局方式，版面与视口原样保留）；
- 新打开的标签页 MUST 以「手动摆放」起步——位置是整理好的，不该被自动布局冲掉。

#### Scenario: 子图里换布局不影响主图

- **WHEN** 在「compute_initial_conditions」子图里把布局换成力导向
- **THEN** 该子图按力导向重排；切回主图时五条层带仍是原来的位置与间距

#### Scenario: 切回子图仍是自己的版面

- **WHEN** 换成力导向后再切到主图、再切回该子图
- **THEN** 该子图保持力导向排出的版面与自己的缩放/平移，不被再次重排

### Requirement: 标签页内按层整理布局

「整理布局」动作 MUST 只作用于当前激活标签页所呈现的可见内容：自底向上排列——先把各装饰容器（层带 / E lane / S09 框）内部的模块排成带并令框自动合围，再排列该标签页的顶层节点与容器；MUST NOT 移动其它标签页的节点。主图标签页 MUST 把五条层带竖排、带内模块横排（图一的读法）；其它标签页沿用同一套「容器竖排成带、带内横排」骨架。整理完成后 MUST 自动取景使本层内容完整可见；整理 MUST NOT 改变节点的 parent 归属或容器/模块角色。

#### Scenario: 只整理当前标签页

- **WHEN** 在「④红移循环」标签页触发整理布局
- **THEN** 仅该层 7 个步骤节点被重新排列，主图与其它子图的节点坐标不变

#### Scenario: 主图保持层带竖排

- **WHEN** 在主图标签页触发整理布局
- **THEN** 五条层带按 ①→②→③→④→⑤ 自上而下排列，每条带里的模块横排（超过 7 个才折行），带框恰好合围自己的模块

#### Scenario: 装饰框自动合围

- **WHEN** 在「入口 B」标签页触发整理布局
- **THEN** E1/E2/E3 三个 lane 各自的步骤先在框内排齐，lane 框恰好合围其步骤（无重叠、无过大空隙），三个 lane 再整齐排列
