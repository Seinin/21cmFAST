## MODIFIED Requirements

### Requirement: 默认使用内置层级布局

打开图谱时画布 MUST 默认使用 cytoscape **内置**的层级布局：根节点在上、按层自上而下铺开，使「谁是谁的细分」在无分组容器的情况下仍可一眼读出。打开（含刷新页面）时画布 MUST 按当前所选布局算法重排一次，MUST NOT 沿用与当前布局不一致的历史存档坐标。为满足该要求 MUST NOT 新增任何第三方布局依赖（不得引入 dagre、elk 等扩展）。工具条 MUST 保留布局算法切换，切换后 MUST 立即按所选算法重排；重复选择「当前已选」的方案 MUST 同样触发一次重排与取景（与显式「重排」等价），MUST NOT 因所选方案未变化而什么都不做。层级布局 MUST 始终可选。重排产生的坐标属于**本机未保存改动**：它 SHALL 只改本机并标记为未保存，MUST NOT 自动写盘；要让它进入工作文件，须由用户手动保存（保存会先把本机坐标批量写回工作文件）。

#### Scenario: 打开即为层级布局

- **WHEN** 打开图谱且未手动切换过布局
- **THEN** 顶层节点位于上方，其子节点位于其下方一层，按层依次铺开

#### Scenario: 打开时按当前布局重排一次而非沿用历史坐标

- **WHEN** 存档中的节点坐标与当前布局算法产出的坐标不一致（例如早期由力导向算法保存的坐标），打开图谱
- **THEN** 画布按当前布局算法重新排布一次，打开后的画面即为层级排布，重排结果作为本机未保存改动（不自动写盘）；同一份数据每次打开得到相同结果

#### Scenario: 仍可切换其它布局

- **WHEN** 从工具条把布局切换到力导向
- **THEN** 画布立即按力导向重排，且状态条显示的布局名称随之更新

#### Scenario: 重复选择同一方案也重排一次

- **WHEN** 当前已是层级布局、画面位置显得凌乱（例如展开/拖动后节点错落），用户再次从工具条选择「层级」
- **THEN** 画布立刻按层级重排一次并取景，不因所选方案与当前一致而跳过

#### Scenario: 不新增布局依赖

- **WHEN** 检查依赖清单与构建产物
- **THEN** 依赖中没有 dagre、elk 等层级布局扩展，层级布局来自 cytoscape 内置实现
