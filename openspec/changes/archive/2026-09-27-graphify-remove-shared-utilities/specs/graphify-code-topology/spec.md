## REMOVED Requirements

### Requirement: 复用件的认定口径

**Reason**: 「复用件」这一要素类别整体撤除：它以节点标记的形式把「被多方调用的通用件」显式建模，但使用后判定收益不足——该信息在节点摘要与源码引用里本来就读得到，而独立类别额外带来标记维护、标识绘制与四个交互入口的成本。

**Migration**: 不再对任何节点做该标记；数据侧的标记已清空。若仍需识别通用件，直接读节点摘要与源码引用（`refs`），或用源码检索临时分析（原本为此写的审计脚本已随本次变更删除）。

### Requirement: 同名模块全部打标

**Reason**: 该要求只在「存在复用件标记」的前提下才有意义，标记本身已撤除。

**Migration**: 无需迁移：字段不存在，同名节点仍按既有「同名模块是同一个实例」的口径保持同步（该口径由别的要求承载，未受影响）。

### Requirement: 复用件标记在数据链路中不丢

**Reason**: 字段与语义都已移除，其读写/合并/草案链路的持久化要求随之作废。

**Migration**: 数据文件已清空该键；服务端 schema 不再声明它。注意历史快照（`data/history/`）与旧备份里仍带该键——**恢复这类文件前需先删掉该键**（节点 schema 为 `additionalProperties: false`，带未知字段将被拒绝）。
