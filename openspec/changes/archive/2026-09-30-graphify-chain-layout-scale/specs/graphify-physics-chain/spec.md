## ADDED Requirements

### Requirement: 一级摆位的尺寸与距离同源

物理链页一级的摆位 MUST 由**两个数**决定，且只能是这两个数：**框的宽高**问尺寸口径（`src/graph/labels.ts`，与画布画框用的是同一套公式），**间距**是一个与框大小无关的常数（`GAP`）。生成器 MUST NOT 用写死的框尺寸去铺坐标（同一份"框有多大"不许有两套数）。

由此 MUST 成立三条：

1. **成比例**：块、块内成员、成员内步骤、框外带，一律按各自的实测宽高依次让开，间距恒为 `GAP`；每排的高度 MUST 取该排最高的框，排间空隙同样恒为 `GAP`。同一块的成员 MUST 仍与自己块同一条水平带（y 相同）。
2. **距离不过大**：任何相邻两框之间的空隙 MUST NOT 超过这两框里**较小的那条短边**（空的地方不许比实的地方还大）。
3. **全图一个间距**：同排的块、同块的成员、同成员的步骤、相邻两排，量到的空隙 MUST 是同一个数（四处排法各自独立，但必须落在同一个间距上）。

尺寸口径在脚本侧 MUST 只有一份副本（`scripts/lib/boxSize.mjs`），且该副本与 `labels.ts` MUST 逐字同口径；脚本内部 MUST NOT 各自再写一份尺寸公式。自检 MUST 用**画布的口径**（真跑 `labels.ts`）量框，MUST NOT 抄一份公式来量。

#### Scenario: 框大，整片跟着大

- **WHEN** 某个块的名字变长（折成两行、框高从 38 变成 45）并重新生成
- **THEN** 它所在那一排的行高随之变成 45，下一排整体下移；排间空隙仍是同一个常数

#### Scenario: 写死步长会被当场抓住

- **WHEN** 把某一处的间距改回写死的坐标步长（如 300）并重新生成
- **THEN** `npm run check:chain` 失败，报出量到的两个间距值（如 `182.5 / 24.0`），退出码 1

#### Scenario: 距离不许比尺寸还大

- **WHEN** 生成物里出现一个空隙大于相邻两框较小的那条短边（如空隙 182.5、短边 38）
- **THEN** 自检报出这对框与两个数，失败

#### Scenario: 两份口径漂移会被发现

- **WHEN** 只改了 `labels.ts`（或只改了 `scripts/lib/boxSize.mjs`）的字号 / 内边距 / 折行规则
- **THEN** 生成物的坐标（按副本算）与画布尺寸（按 `labels.ts` 算）不再吻合，空隙不再是同一个数，`check:chain` 的「全图一个间距」断言失败

#### Scenario: 不打开浏览器也能读到"字多大"

- **WHEN** 跑 `npm run check:chain`
- **THEN** 输出里有一行 `一级版面 <宽> × <高>（框 <宽域> 宽 × <高域> 高，空隙 <值>）：取景倍数 ≈ 画布高 / <高>，屏幕字号 = 13 × 那个倍数`
