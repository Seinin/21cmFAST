## Context

一级（12 个块）的坐标由 `scripts/build-physics-chain.mjs` 生成，宽高则由画布在运行时按标签算（`src/graph/labels.ts` → `data(boxW/boxH)`）。两者各自演化到现在，已经不是一套数：生成器按 820×300 铺，画布算出 116~240×38~45。取景（`cytoscapeSetup.fit()`，只在可见节点上取景、缩放夹在 [0.85, 1.45]）把这个不一致放大成了"看不见全链 / 字读不出"。

## Goals / Non-Goals

- **Goal**：一级摆位的空隙由框的尺寸决定，且小到能用一块画布把整链看全、字还能读。
- **Goal**：这条口径可证伪——写死步长、间距过大、两份口径漂移，都要被自检抓住。
- **Non-Goal**：不动真源（`chain.json`）、不动 `labels.ts` 的公式、不改框的样式、不引入布局库。

## Decisions

### D1 间距是常数，尺寸问口径（而不是"把间距调小一点"）

只把 820/300 换成一组更小的数（如 200/80），病还在：将来标签变长、框变高，两套数又会分叉。真正的解法是**消掉"生成器以为的框尺寸"这个量**——坐标 = f(实测宽高, 常数间距)。常数间距取 `GAP = 24`（与 `normalize-layout.mjs` 同值，"够分清彼此、又不浪费屏幕"）。代价：口径必须共享（见 D2）。

### D2 尺寸口径在脚本侧留一份**物理副本**，并由自检盯着两份等价

`labels.ts` 是 TS，`node scripts/*.mjs` 里 import 不了（除非 esbuild 打包，那会把脚本变成构建产物）。三种走法：

| 方案 | 为什么否 |
|---|---|
| 生成器 import TS（esbuild 打包） | 生成脚本变成"要先构建"的东西；每跑一次几百 ms；产物路径要进 `.gitignore`，多一份可失效的中间物 |
| 生成器继续各写一份公式 | 就是现在的病：两份数各自演化 |
| **抽一份 `.mjs` 镜像（采用）** | 单一副本、零构建；代价是"两份物理副本"，用自检盯住 |

采取的做法：新增 `scripts/lib/boxSize.mjs` 作为**脚本侧唯一副本**，文件头写明"两份物理副本，改一边要同步另一边"；脚本内部（`build-physics-chain.mjs` / `normalize-layout.mjs`）一律 import 它，不再各写一遍。等价性不靠人记：`check:chain` 用 esbuild **真跑 `labels.ts`** 量框，凡是坐标与尺寸不吻合，量到的空隙就不再是同一个数（见 D4）。另外做过一次全量核对：两个数据集里 390 个 label（含大框）逐个比对，0 处不一致。

### D3 自检用画布口径量框，而不是抄一份公式

如果自检也抄一份公式，那它就是"第三份副本"，而且会和生成器错得一样——抄一份来验另一份，什么也验不出来。所以自检 esbuild 真跑 `src/graph/labels.ts`（`loadTs` 已有此机制，`check:tabs` 同样在做）。这同时把"镜像副本是否漂移"这件事变成了免费的检查项：**生成器的坐标来自副本，自检的尺寸来自 `labels.ts`，两者一旦分叉，空隙立刻不是同一个数。**

### D4 两条断言，分工不同（都只量成品）

- **距离由尺寸定**：把所有相邻空隙（同排的块 / 同块的成员 / 同成员的步骤 / 相邻两排）收进一个集合，要求**集合只有一个数**。它比"逐组内部相等"强——旧稿的 820 / 300 / 280 / 220 是**四处各一套**，任何一处另起一套步长都会让集合多出一个数。这条同时兼作 D2 的漂移检查。
- **距离不过大**：每个空隙 ≤ 相邻两框里较小的那条短边。这条与"间距的具体值"无关（不 import 生成器的 `GAP` 常数），是**尺寸相对**的判据：空的地方不许比实的地方还大。旧稿的空隙 805 / 262 会被它抓住。

被否的替代判据：断言"间距 == GAP"（要 import 生成器的常数，等于自查自；且间距将来真该改时，断言会变成噪音）、断言"取景后字号 ≥ 10px"（取景依赖运行时窗口尺寸，脚本里只能假设一个画布大小，会把一个主观假设写成断言）。

### D5 反面演练是验收的一部分

两条断言都做了一次"把病种回去"：把某一处改回 `index * 300` 的写死步长 → `40 处空隙量到 182.5 / 24.0` 与 `空 182.5（短边才 38）`，退出码 1；恢复后重建，产物哈希戳记与演练前逐字相同（幂等）。断言不是摆设。

### D6 不改变语义结构

只动坐标：块的主序位次（`order`）、块的成员归属、成员同带、步骤挂在量下面——全部照旧（原断言继续生效）。蛇形两列排布能把版面再压一半（取景会顶到 1.45、字 18px），但那会把"位次 = 一排"这个读法弄乱，超出本次要求，留作备选。
