## ADDED Requirements

### Requirement: 参数词条按代码类名分组

物理链页的参数词条 MUST 按**代码里的参数类名**分组（当前为 `AstroParams` / `CosmoParams` / `AstroOptions`），分组名 MUST 来自生成物 `param.group` 字段，视图 MUST NOT 写死分组名单，也 MUST NOT 按生成物里的数组名（`drivers` / `astro` / `cosmo` / `numeric` / `effects`）分组——同一份参数在不同数组里可能属于不同的类。词条 MUST 只列"能落到图上某个量或边"的参数（在参数 × 节点矩阵里有条目），并写出它作用的模块数。分组与词条 MUST 给出条数。

#### Scenario: 分组名就是代码里的类名

- **WHEN** 打开物理链页、检索框为空
- **THEN** 词条按 `AstroParams` / `CosmoParams` / `AstroOptions` 分组列出，每组标出条数；不出现"天体物理参数 / 宇宙学参数"这类手写分组

#### Scenario: 分组的来源是字段而不是数组名

- **WHEN** 查看 `R_MAX_TS`（在生成物的 `numeric` 数组里、`group` 是 `AstroParams`）
- **THEN** 它出现在 `AstroParams` 组里

#### Scenario: 点不亮的参数不列

- **WHEN** 某个参数在参数 × 节点矩阵里没有条目（没有归属模块）
- **THEN** 它不出现在词条列表里

#### Scenario: 分组改了视图不用改

- **WHEN** 生成物里某个参数的 `group` 改成别的类名并重新生成
- **THEN** 它出现在新的分组下，页面代码无需改动

### Requirement: 选中参数点亮过程块与产物

选中一个参数时，画布 MUST 高亮**所有持有该标签的对象**，且 MUST 覆盖两个层级：一级的**过程块**（成员里有量读这个参数的块）与块内的**产物**（读了它的物理量 / 驱动量）。生成物 MUST 为每个块给出**成员标签的并集**（与块已有的 `stages` 并集同一条口径），该并集 MUST 由自检独立重算核对。选中参数 MUST NOT 把选中落在一个当前看不见的对象上：本页 SHALL 选中它作用的**第一个块**（右侧栏随之给出过程块的属性页）。

#### Scenario: 一级看得见反馈

- **WHEN** 在侧栏点中参数 `F_STAR10`
- **THEN** 画布上 ③星系形成与源项、④电离史、⑤气体热史 三个块亮起（它们各有成员读这个参数），右侧栏显示第一个块的属性

#### Scenario: 进块后产物也亮

- **WHEN** 选中 `F_STAR10` 后进入 ③星系形成与源项
- **THEN** 该块内读这个参数的产物（如 `ρ̇*(z)`）也带着标签高亮

#### Scenario: 块上没有自己的标签

- **WHEN** 运行物理链自检
- **THEN** 每个块的标签集合恰好等于它成员的标签并集；自检独立重算一遍，多一个、少一个都判失败并指出差在哪

#### Scenario: 装饰容器不参与标签

- **WHEN** 运行画布自检（画布页的大框是 `type: 'group'` 的装饰容器）
- **THEN** 勾选标签后装饰容器不亮红点（既有断言保持通过）

## MODIFIED Requirements

### Requirement: 本页检索与来源标注

物理链页的检索 MUST 只用本页生成物（`physics-chain.json`），MUST NOT 使用画布页的数据，也 MUST NOT 改动画布页的选中状态。检索 SHALL 覆盖四路：参数、物理量、过程名、论文出处。每条命中 MUST 标注它属于哪个块（如「④电离史」「⑨观测量」；没有归属的按生成物给的字面标注）。选中命中项后 MUST 在本页定位（选中该对象或进入它所属的块）。

检索结果 MUST 按四类**分组呈现并给出每类的条数**（计数 MUST 来自检索本身算出的结果，MUST NOT 写死）。参数命中 MUST 写出它所属的代码类与它落到哪几个块。节点命中 MUST 写出它的代码阶段号，且**阶段号本身 MUST 是命中面**（按 `S14` 检索能找到算在那段代码里的量）。检索输入框 MUST 支持键盘操作：↑/↓ 移动当前命中、Enter 定位当前命中、Esc 清空检索词。

#### Scenario: 命中参数

- **WHEN** 在物理链页检索一个参数名（如 `F_STAR10`）
- **THEN** 结果给出它作用的物理量、它门控的开关边、它所属的代码类（`AstroParams`）与它落到哪几个块，并注明数量

#### Scenario: 命中后按类分组并给出计数

- **WHEN** 检索「电离」
- **THEN** 结果按参数 / 物理量 / 过程 / 文献分组显示，每类顶部给出该类的命中条数，且条数与实际列出的项数一致

#### Scenario: 按代码阶段号检索

- **WHEN** 检索 `S14`
- **THEN** 命中算在 S14 这段代码里的量（结果里写明它们的阶段号）

#### Scenario: 键盘走完一次检索

- **WHEN** 在检索框里按 ↓ 两次再按 Enter
- **THEN** 当前项移到第三条命中并定位到它；按 Esc 清空检索词与命中列表

#### Scenario: 命中只存在于收起条里的对象

- **WHEN** 检索一个不在当前标签页可见集里的对象（如只在 ⑤气体热史 块内的 `ε_heat`）
- **THEN** 该结果标注它所属的块名（「⑤气体热史」）；选中后本页定位到该对象——它不在当前标签页就先切到它所属的块再选中

#### Scenario: 命中过程名与论文出处

- **WHEN** 检索一个过程名（如「电离史」）或一处论文出处
- **THEN** 分别命中对应的块 / 带该出处的量，并在结果里标注来源

#### Scenario: 不污染画布

- **WHEN** 在物理链页检索并选中一个结果，然后切回画布页
- **THEN** 画布页的选中状态与它的数据没有被这次检索改动

#### Scenario: 切视图清空检索词

- **WHEN** 从任意一页切到另一页
- **THEN** 检索词与检索面板回到空状态（两个方向都清，不把一页的关键词带进另一页）
