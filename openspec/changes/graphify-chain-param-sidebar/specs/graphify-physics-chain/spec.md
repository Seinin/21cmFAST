## ADDED Requirements

### Requirement: 参数词条按代码类名分组

物理链页的参数词条 MUST 按**代码里的参数类名**分组（当前为 `AstroParams` / `CosmoParams` / `AstroOptions`），分组名 MUST 来自生成物 `param.group` 字段，视图 MUST NOT 写死分组名单，也 MUST NOT 按生成物里的数组名（`drivers` / `astro` / `cosmo` / `numeric` / `effects`）分组——同一份参数在不同数组里可能属于不同的类。词条 MUST 收**全部登记参数**（生成物 `params` 各组的并集，含在参数 × 节点矩阵里没有条目的那些）——一个参数在图上没有落点不构成"它不存在"，MUST NOT 因此把它从列表里丢掉。没有落点的词条 MUST 标出"未落图"并在悬停提示里写明是**哪一种**「无」（矩阵里没有条目 / 代码里没有它）。只门控边的开关**不算没有落点**：它在代码里没有读点，但那条边在图上挂着两个量，这两端就是它的去处——词条 MUST 落到这两端（悬停提示写出它门控的是哪条边与"为真时改走哪几个量那一支"），MUST NOT 写成「作用于 0 个量」。它的作用处数 MUST 可读（退到该行悬停提示），MUST NOT 印在词条行上。分组 MUST 给出条数。

#### Scenario: 分组名就是代码里的类名

- **WHEN** 打开物理链页、检索框为空
- **THEN** 词条按 `AstroParams` / `CosmoParams` / `AstroOptions` 分组列出，每组标出条数；不出现"天体物理参数 / 宇宙学参数"这类手写分组

#### Scenario: 分组的来源是字段而不是数组名

- **WHEN** 查看 `R_MAX_TS`（在生成物的 `numeric` 数组里、`group` 是 `AstroParams`）
- **THEN** 它出现在 `AstroParams` 组里

#### Scenario: 点不亮的参数照样列出来

- **WHEN** 某个参数在参数 × 节点矩阵里没有条目（没有归属模块，如 `MAX_DVDR`）
- **THEN** 它仍出现在它那个代码类名分组里，行上带"未落图"标记，悬停提示写明原因（如"链上没有量落在读到它的那段代码上"）
- **AND** 点它不点亮画布上任何对象（它没有落点），但选中状态与左栏脚上区的说明照常给出

#### Scenario: 只门控边的开关写在那条边的两端

- **WHEN** 查看 `USE_UPPER_STELLAR_TURNOVER`（`AstroOptions` 里的开关，矩阵里只有边 `fstar->scaling_relations`、没有节点）
- **THEN** 悬停提示写出门控的是哪条边（两端用页面上那两个量的符号，如 `f* → 标度关系(M_h)`）与"为真时改走 2 个量那一支"，MUST NOT 出现"作用于 0 个量"
- **AND** 左栏脚上区多出一行「门控」，列出这两个量（可点、点了定位过去）；「属于」与块归属也按这两端算——它落在哪条过程上，靠的就是这条边

#### Scenario: 分组改了视图不用改

- **WHEN** 生成物里某个参数的 `group` 改成别的类名并重新生成
- **THEN** 它出现在新的分组下，页面代码无需改动

### Requirement: 选中参数点亮过程块与产物

选中一个参数时，画布 MUST 高亮**所有持有该标签的对象**，且 MUST 覆盖两个层级：一级的**过程块**（成员里有量读这个参数的块）与块内的**产物**（读了它的物理量 / 驱动量）。生成物 MUST 为每个块给出**成员标签的并集**（与块已有的 `stages` 并集同一条口径），该并集 MUST 由自检独立重算核对。选中参数 MUST NOT 把选中落在一个当前看不见的对象上：本页 SHALL 选中它作用的**第一个块**（右侧栏随之给出过程块的属性页）。

#### Scenario: 一级看得见反馈

- **WHEN** 在侧栏点中参数 `F_STAR10`
- **THEN** 画布上 ③星系形成与源项、④电离史、⑤气体热史 三个块亮起（它们各有成员读这个参数），右侧栏显示第一个块的属性

#### Scenario: 进块后产物也亮

- **WHEN** 选中 `F_STAR10` 后进入 ③星系形成与源项
- **THEN** 该块内读这个参数的产物（如 `ρ̇*(z)`）也带着标签高亮

#### Scenario: 块上没有自己的标签

- **WHEN** 运行物理链自检
- **THEN** 每个块的标签集合恰好等于它成员的标签并集；自检独立重算一遍，多一个、少一个都判失败并指出差在哪

#### Scenario: 装饰容器不参与标签

- **WHEN** 运行画布自检（画布页的大框是 `type: 'group'` 的装饰容器）
- **THEN** 勾选标签后装饰容器不亮红点（既有断言保持通过）

## MODIFIED Requirements

### Requirement: 本页检索与来源标注

物理链页的检索 MUST 只用本页生成物（`physics-chain.json`），MUST NOT 使用画布页的数据，也 MUST NOT 改动画布页的选中状态。检索 SHALL 覆盖四路：参数、物理量、过程名、论文出处。每条命中 MUST 标注它属于哪个块（如「④电离史」「⑨观测量」；没有归属的按生成物给的字面标注）。选中命中项后 MUST 在本页定位（选中该对象或进入它所属的块）。

检索结果 MUST 按四类**分组呈现并给出每类的条数**（计数 MUST 来自检索本身算出的结果，MUST NOT 写死）。参数命中 MUST 写出它所属的代码类与它落到哪几个块。节点命中 MUST 写出它属于哪个块；**阶段号本身 MUST 是命中面**（按 `S14` 检索能找到算在那段代码里的量），但命中说明 MUST NOT 印出编号。检索输入框 MUST 支持键盘操作：↑/↓ 移动当前命中、Enter 定位当前命中、Esc 清空检索词。

#### Scenario: 命中参数

- **WHEN** 在物理链页检索一个参数名（如 `F_STAR10`）
- **THEN** 结果给出它作用的物理量、它门控的开关边、它所属的代码类（`AstroParams`）与它落到哪几个块，并注明数量
- **AND** 只门控边的开关（如 `USE_UPPER_STELLAR_TURNOVER`）写出那条边两端的人话（如 `f* → 标度关系(M_h)`）与"为真时改走几个量那一支"，选中时定位到这条边上的量

#### Scenario: 命中后按类分组并给出计数

- **WHEN** 检索「电离」
- **THEN** 结果按参数 / 物理量 / 过程 / 文献分组显示，每类顶部给出该类的命中条数，且条数与实际列出的项数一致

#### Scenario: 按代码阶段号检索

- **WHEN** 检索 `S14`
- **THEN** 命中算在 S14 这段代码里的量，且每条的说明只写它属于哪个块

#### Scenario: 命中说明里不印阶段号

- **WHEN** 按 `S14` 检索（内部编号是命中面之一）
- **THEN** 命中的量与过程都在结果里出现，但每条的说明只写"属于哪个块"，MUST NOT 出现「代码 S14」这样的字样

#### Scenario: 键盘走完一次检索

- **WHEN** 在检索框里按 ↓ 两次再按 Enter
- **THEN** 当前项移到第三条命中并定位到它；按 Esc 清空检索词与命中列表

#### Scenario: 命中只存在于收起条里的对象

- **WHEN** 检索一个不在当前标签页可见集里的对象（如只在 ⑤气体热史 块内的 `ε_heat`）
- **THEN** 该结果标注它所属的块名（「⑤气体热史」）；选中后本页定位到该对象——它不在当前标签页就先切到它所属的块再选中

#### Scenario: 命中过程名与论文出处

- **WHEN** 检索一个过程名（如「电离史」）或一处论文出处
- **THEN** 分别命中对应的块 / 带该出处的量，并在结果里标注来源

#### Scenario: 不污染画布

- **WHEN** 在物理链页检索并选中一个结果，然后切回画布页
- **THEN** 画布页的选中状态与它的数据没有被这次检索改动

#### Scenario: 切视图清空检索词

- **WHEN** 从任意一页切到另一页
- **THEN** 检索词与检索面板回到空状态（两个方向都清，不把一页的关键词带进另一页）
