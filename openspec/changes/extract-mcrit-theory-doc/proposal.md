# 把 mcrit 的 FDM 剖面推导从 FDM.md 中分出来

## Why

`docs/FDM.md` 第三篇现在把两件事写在同一份文件里：一件是对仓库现状的说明与 CDM 基线审计（§1–§3、§7–§8、附录），另一件是从 FDM 孤子密度剖面出发推导 `m_crit^FDM` 的物理模型（§4–§6、§9、§10）。合在一起带来三个具体后果：

1. 要读剖面推导，得先穿过 §3 的 530 行代码索引（`thermochem.c` / `scaling_relations.c` 的调用链、Fialkov+12 拟合公式每一项的来源核对），才能看到 §4 的第一条密度剖面公式；
2. 要实现 §5.12 的判据，得在 §7（`thermochem.c` 怎么改）与 §5（要改成的公式）之间来回翻同一份 2940 行的文件；
3. §4–§6 的行文方式是"结论 + 表格 + 断言"（多处「关键观察：」「结论：」「认知地位」「底线」），推导链上每一步的输入、假设与假设失效后的后果散落在表格的注释里，读者无法沿公式顺序自己判断某一步有多强。

推导链本身在 `fix-fdm-soliton-scalings` 中已经核对并复算过，数值是稳定的；现在缺的是一份能按公式顺序往下读、并且把每一步的输入与假设讲清楚的理论文档。

## What Changes

**新增 `docs/FDM_mcrit_theory.md`**（自成一册，带自己的节号、导航与参考文献）：

- 迁出第三篇 §4：孤子平核剖面、$M_{\rm core}$ 与 $(r_c, M_c)$ 的标度律、$M_{\rm sol}(m_{22}, z)$、以 $M_{\rm sol}$ 划分的三个质量区间、对气体密度与冷却的影响
- 迁出 §5：冷却判据、抑制因子 $\eta$ 的定义、为什么自变量取 $M_h/M_{\rm sol}$、隐式方程 (★)、$\eta_p$ 的形式与两条渐近行为、$L_k$ 对照族为什么不能表示方程 (1) 的解、最终公式、方程 (1) 的数值验证与族外偏离
- 迁出 §6：$M_{\rm sol}$ 与 $R(z)$ 表、$m_{\rm crit}^{\rm FDM}(m_{22}, z)$ 表、$\exp(-m_{\rm crit}/M_h)$ 截断效率表、$z=10$、$m_{22}=1$ 的完整算例
- 迁出 §9：与 Tocher+2026 的对照、波动力学修正因子 $f_{\rm wave}$
- 迁出 §10.1–§10.7：当前做得到与做不到的检验、定量的不确定度来源
- 迁出 §11 参考文献表（引用绝大多数落在上述几节）

**改写要求（本次的主要工作量）**：迁出的内容按"解释"重写，而不是搬移后润色措辞：

- 引入一个量时，先写它是什么、从哪里来、下一步要用它做什么，再给公式；公式后交代符号与单位
- 每用一条假设（$\eta$ 只依赖 $M_h/M_{\rm sol}$、$r_{\rm cool} \sim 0.1\,r_{\rm vir}$、$n_H^{\rm CDM} \propto M_h^{\gamma}$、中心值 $p=1$、$\gamma=0.1$），写清它成立的范围，以及它不成立时结论会怎样变（例如 $\gamma = 0$ 时方程无有限解；$a$ 的幂次若取 $-1/4$，§6 的红移演化方向翻转）
- 数值表保留（它们是数据，不是结论），但表前写输入与取值来源，表后写误差范围与哪些结论不宜外推
- 去掉含糊与修辞性说法：「认知地位」「坦承」「底线」「黄金标准」「可导出、非假设」「自然的变量选择」「非平凡的支撑」「robust」「物理上可信」等，改为陈述"这一步依赖什么、范围多大、假设不成立会怎样"
- 不用 verdict 表格（"可靠 / 量级正确性高"这类评价）代替推导说明

**`docs/FDM.md` 的调整**：

- 第三篇保留 §1–§3（问题定义、`mcrit_noLW` 在代码中的角色、CDM 基线的物理起源）、§7–§8（`thermochem.c` 实现、与已有 FDM 基础设施的关系）与附录 A/B/C

- 被迁出的 §4–§6、§9、§10.1–§10.7 位置留一段导航说明：哪些内容移到哪份文档、新旧节号如何对应
- 保留段落中指向 §4–§6、§9、§10 的交叉引用改指新文档（含 §7.2 里的「见 §9.2」、§3.3.5d 里的「数值表见 §6.1–6.3」、附录 A/C 里的引用）
- 参考文献表迁出后在第三篇留一行指针
- 第三篇的「来源：`docs/FDM_mcrit_algorithm.md`」标注已失效（该源文件已不存在，`docs/FDM.md` 现在就是正本），一并更正
