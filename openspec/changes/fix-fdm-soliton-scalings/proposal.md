# 修正 FDM 孤子标度律并存下游数值重算

## Why

`docs/FDM.md` §4.1–§4.3 的三条孤子标度律与权威出处（Schive+14, PRL 113, 261302, Eqs. 3–7）不一致，误差随 §5.12 传播到 §5.13 与 §6 的全部数值：

| 项 | 文档现值 | 权威值（Schive+14 Eq. 3/6/7） |
| --- | --- | --- |
| $r_c$ 的 $m_{22}$ 幂次 | $-2/3$ | $-1$（Eq. 7: $r_c = 1.6\,m_{22}^{-1}a^{1/2}(\zeta/\zeta_0)^{-1/6}(M_h/10^9)^{-1/3}$ kpc） |
| $M_{\rm core}$ 系数 | $6.2\times10^7 m_{22}^{-1}$ | $3.1\times10^7 m_{22}^{-1}$（Eq. 6 在 $z=0$ 的数值形式） |
| $M_{\rm sol}$ | $1.54\times10^7 m_{22}^{-3/2}$ | $5.47\times10^6 m_{22}^{-3/2}(1+z)^{3/4}(\zeta/\zeta_0)^{1/4}$ |

两个独立矛盾：$r_c\propto m_{22}^{-2/3}$ 与 $M_{\rm core}\propto m_{22}^{-1}$ 不可能同时成立（孤子标度 $M_c r_c\propto m_{22}^{-2}$ 要求 $r_c\propto m_{22}^{-1}(M_h/10^9)^{-1/3}$）；系数 $6.2\times10^7$ 来自把 $(m_a/2\times10^{-22})^{-1}$ 误当作 $(m_a/10^{-22})^{-1}$。

## What changes

1. §4.1 改为 Eq. 7 的完整形式（含 $a^{1/2}$、$(\zeta/\zeta_0)^{-1/6}$），并给出与 $M_{\rm core}$ 的一致性核对。
2. §4.2 系数改为 $3.1\times10^7$，角标基准改为 $M_h/10^9$。
3. §4.3 给出 $M_{\rm sol}(m_{22},z)=5.47\times10^6 m_{22}^{-3/2}(1+z)^{3/4}(\zeta/\zeta_0)^{1/4}$；$z=0$ 值 $5.47\times10^6 m_{22}^{-3/2}$。
4. §5.3 用新 $r_c$ 重推 $M_{\rm eq}$：得 $M_{\rm eq}\propto m_{22}^{-3/2}(1+z)^{3/4}$，与 $M_{\rm sol}(z)$ **同幂次同红移标度**，故 $\eta=\eta(M_h/M_{\rm sol})$ 由「建模假设」升格为「可导出」。
5. §5.11–§5.13、§6.1–§6.4、§7.1 按新输入重算全部数值。

## Impact

- 仅 `docs/FDM.md`（文档），无代码改动。
- 结论方向不变（FDM 阈值相对 CDM 的抬升随 $z$ 增强），但绝对幅度和「$m_{\rm crit}^{\rm FDM}$ 随 $z$ 几乎冻结」的说法要改写为「随 $z$ 上升」。
- 未解决项照旧记在 $(\eta,\gamma)$ 与 $r_{\rm cool}$ 上。
