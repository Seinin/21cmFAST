## Why

物理链页左栏与画布页 notes 列表被一层「解释性小字」塞满：过程词条下挂着量数 / 相关参数数 / 论文出处数再加一行拟合律口径，参数行右侧压着 PL2012 符号与「N 处」，检索命中行下面各带一句说明，notes 文档行下再重复一行文件名。这些字都在说同一件事的第二遍（数字进不了决策、文件名与标题指的是同一篇文档），却把可点的名字挤成小字。同一栏里还有一块会撑满整栏高的东西：选中 `USE_MINIHALOS` 这类作用于很多量的参数后，脚上「作用于 N 个量」那块标签一路铺开，把上面的词条清单整块顶出视野，长的那块只能靠整栏滚动去够。

## What Changes

- **左栏词条行只留名字**：过程词条行只写过程名（保留「带」/「口径待核」状态徽标），参数词条行只写参数名。被去掉的四类小字——过程词条的量数 / 相关参数数 / 论文出处数、拟合律口径一行、参数行的 PL2012 符号与「N 处」、检索命中行的说明句——**退到该行的悬停提示（`title`）**，查阅不丢信息（与「清单里只给文件名、完整路径退到 `title`」同一套做法）。
- **选中参数的脚上区封顶**：脚上区只写参数名 + 代码类名徽标 + 可点的量 / 过程清单；「作用于 N 个量，落在 …」这句并进悬停提示。该区总高度 MUST 不超过左栏的一半，更长时在区内滚动，上面的词条清单不再被顶走。
- **开关标签去计数**：浮层上的「跨红移反馈」开关标签只写开关名与开 / 关，不再写「· N 条」；藏了几条仍由生成物算出，并留在悬停提示里（连同它管哪些视图面），口径照样报全。
- **画布页 notes 列表去文件名**：文档行只留标题，不再在标题下重复一行等宽文件名（行的 `title` 仍是 `docId`）。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `graphify-physics-chain`：
  - 「左栏并排两个检索面」——过程词条「必须给三条信息」与参数词条行右侧小字改为「行上只写名字、计数与拟合律退到悬停提示」，并新增脚上区高度封顶与区内滚动；
  - 「本页检索与来源标注」——命中行不再印说明句（说明退到悬停提示），「属于哪一层」改由状态徽标承担；
  - 「开关报数并记在本机」——条数从开关标签退出，改为只在悬停提示里可读。
