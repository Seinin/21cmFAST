## Context

左栏（`ChainSearchPanel.tsx`）是纯入参组件：计数与说明都由页面从数据层算好递进来——`ChainProcessEntry` 带 `memberCount` / `paramCount` / `paperCount` / `fit`，`ChainParamEntry` 带 `nodeCount` / `pl2012`，`ChainHit` 带 `detail`，`ChainParamEffect` 带 `blocks` / `nodes` / `processes`。要动的只是渲染面，数据层与生成物一行都不用改。

两条既有先例决定做法：证据清单里「落点只给不带目录的文件名、完整路径退到 `title`」（信息都在，只是不铺在行上），以及画布页 notes 列表的文档行 `title={doc.docId}`。脚上区的高度问题与之无关，是布局问题：它现在是 `shrink-0` + 自由换行的 chip 墙，选中 `USE_MINIHALOS` 这类参数时 chip 数量把它顶成整栏高，把上面的词条清单挤出视野。

## Goals / Non-Goals

**Goals:**

- 左栏可点的名字成为视觉主体，解释性小字从行上退场、但仍可查到。
- 脚上区在任何参数下都不超过左栏一半高，词条清单始终可见。
- 开关标签只报口径（开 / 关），条数仍可读。

**Non-Goals:**

- 不动数据层、生成物与自检断言（计数仍在，只是换出口）。
- 不动检索的四路覆盖与分组、不动兜底小节结构、不动面板宽度机制。
- 不给脚上区加折叠开关或「更多」按钮。

## Decisions

**1. 计数与说明退到 `title`，而不是整块删除。**
被点名的文本有五种读法：量数 / 相关参数数 / 论文出处数、拟合律口径、PL2012 符号与作用处数、命中说明、块清单。它们是生成物里的事实，删掉只能靠自检或数据文件再找回来；退到悬停提示则保持「行上干净、悬停可查」，与证据清单的既有口径同源。行的 `title` 本来就已经在放其中一部分（参数行给「作用于 N 个量、门控 M 条边」，过程行给 `entry.note`），这次把剩下的并进去。替代方案（整块删除）会让 `ChainProcessEntry.fit` 这类字段在界面上彻底没有出口，得另开一处地方放它们，反而多一块界面。

**2. 脚上区用 `max-h-[50%]` + `overflow-y-auto` 封顶。**
百分比是相对左栏（`aside` 是定高的 flex 列）算的，栏宽怎么拖都成立，不需要测量高度或监听 resize。替代方案：给脚上区加「显示全部 / 收起」开关（多一个控件、默认态仍要选）、或把量清单改成弹层（又造一个浮层，正是这次要减少的东西）。区内出现滚动条是可接受的代价——脚上区本来就是「选中一个参数后的补充面」，不是主清单。

**3. 两个清单各带一个词的头：「作用于」与「属于」。**
两排 chip 里一排是量、一排是过程，没有头就只能靠位置猜。头用一个词，不写句子。

**4. 命中行的「属于哪一层」由既有徽标承担。**
`hit.collapsed` 已经渲染成「旁路与实现细节」徽标，说明句是第二遍。层信息退到 `title` 后，行上留名字 + 徽标。

**5. notes 列表去掉文件名一行，`title` 仍是 `docId`。**
文档列表的行内容没有被任何需求钉住（`graphify-panel-layout` 只管宽度与手柄），所以这一处不产出规格 delta，只记在提案与任务里。

**6. 与 `graphify-chain-param-sidebar` 的口径对齐。**
那个 change 还没归档，它的 ADDED 需求「参数词条按代码类名分组」里写着词条「写出它作用的模块数」；本变更把这条口径改成「作用处数可读（悬停提示）」。两份 change 不能各带一半口径归档，所以在实施时一并改它那一句。

## Risks / Trade-offs

- [悬停提示在触屏上读不到] → 计数不是决策必需项（决定看的是名字与清单），检索面仍给出四类计数；`title` 在桌面端与辅助技术上仍可读。
- [脚上区先出现滚动条、第二眼才知道下面还有 chip] → 区内滚动是既有模式（词条清单本身就是滚动区），且封顶换来的是词条清单不再被顶走。
- [悬停提示变长（过程行同时带计数与拟合律）] → 提示是瞬时层，不影响版面；拟合律口径只在该过程有 `fit` 时才拼进去。

## Migration Plan

纯前端文案与容器类改动，无数据迁移、无 feature flag。回滚＝还原三个组件文件。归档顺序：先归档 `graphify-chain-param-sidebar`（或按其口径同步那一句），再归档本变更。
