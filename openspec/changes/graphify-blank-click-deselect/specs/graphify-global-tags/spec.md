## MODIFIED Requirements

### Requirement: 顶栏标签勾选

顶栏 MUST 提供「标签」入口，列出全部已注册标签、每个标签的**命中节点数**与复选框。勾选状态 MUST 是纯视图状态：MUST NOT 进入撤销栈、MUST NOT 落盘。默认 MUST 一个都不勾选。存在被勾选标签时，界面 MUST 能看出当前勾了哪些（例如入口上显示计数）。

单击画布空白处 MUST 把勾选集合清空，回到默认的「一个都不勾」——与入口里的「清除」等价，红点随之全灭。这次清空 MUST 仍然是纯视图改动（不标脏、不触发保存、不入撤销栈），MUST NOT 改动图谱数据、节点标签归属与红点之外的任何画布状态。

#### Scenario: 勾选后计数可见

- **WHEN** 打开标签入口并勾上「参数参与」
- **THEN** 该标签旁显示被标节点数，入口处能看到「已勾 N 个标签」

#### Scenario: 勾选不产生落盘改动

- **WHEN** 勾选或取消勾选任意标签
- **THEN** 图谱处于「已保存」状态（不标脏、不触发保存）

#### Scenario: 点画布空白取消勾选

- **WHEN** 勾上「参数参与」（画布上亮起红点），然后单击画布空白处
- **THEN** 勾选集合清空、入口计数回到「没有勾选」、画布上不再有红点
- **AND** 图谱仍处于「已保存」状态，节点标签归属未被改动
