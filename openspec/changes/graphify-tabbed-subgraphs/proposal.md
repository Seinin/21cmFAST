## Why

Graphify 当前的导航模型（单一画布 + focus-path 原地展开/下钻）与作者的设计意图不符，实际使用中显得凌乱：70 个节点混在一个文档里按层级展开，用户在界面上手动拖拽拆解后已有 33 个节点脱离父级飘在根层。作者的意图是「多图 + 标签页」，并且进一步明确了组织语义：**大框（图一外框、E lane、S09 框）是装饰性容器**——几个大模块摆放在框内，框只作视觉分组；**展开/导航的单位是模块，不是容器**：双击模块（或属性页入口）在新标签页打开它的内容。当前实现把「容器」与「可展开物」混为一谈，导致模块不在容器里、排布凌乱、「整理布局」全局重排结果不合理。

## What Changes

- 引入**装饰容器 vs 模块**双语义：`type` 为 `group`（大框）的节点是**装饰容器**——子节点直接渲染在框内（复合布局，框自动合围），自身不可进入、不可展开；其余有子节点的节点一律是**模块**——紧凑呈现 + `· N` 徽标，双击或属性页「进入子图 ↗」在新标签页打开其内容（沿用现有 `group` 类型承载装饰容器语义，不新增字段；五个层带相应地从 `group` 改为 `section` 成为模块）。**BREAKING**：移除 focus-path 下钻与原地展开/收起交互（返回按钮、面包屑、展开键、每屏节点预算）。
- 新增**子图标签页导航**：画布上方一条标签栏；「主图」标签固定不可关闭；标签页可切换、可关闭，各自保持独立的缩放/平移/选中状态；当前子图同步到 URL（`?g=<nodeId>`），刷新或另开浏览器标签页可恢复。
- 图谱数据重构（内容节点与边全部保留）：
  - 主图 = `图一` 装饰大框（保留在根层）内竖排 ①入口层 → ②编排层 → ③备料层 → ④红移循环 → ⑤输出层 五个**层模块**，补模块级流向边；
  - 解散 `图二` 大框：E1/E2/E3 三个 lane（装饰容器）挂到 ②编排层 的「入口 B · 三个顶层驱动」模块下；
  - `初始条件（S09）` 装饰框（保留）挂到 ③备料层 的 `compute_initial_conditions` 模块下，S09 的过程节点与输入参数归位进框（产物节点已并入边标签）；
  - 33 个孤儿节点按 id 前缀归位；节点数 70→69（仅删除「图二」一个空壳大框）。
- 属性页（Inspector）新增「进入子图 ↗」按钮（仅对模块显示）。
- 「整理布局」按当前标签页的可见内容执行：自底向上令装饰框自动合围其子节点；主图五层强制单列竖排。

### 复核后追加的修订（用户看图后提出）

- **层是容器、模块是类 / 函数**（按图一的逻辑）：①入口层…⑤输出层这五条层带是**装饰容器**（`group`，带内直接画这一层的模块框），它们提升为主图根节点；原来把它们圈起来的 `图一 · 主调度链` 外框多余，解散。**模块**专指类 / 函数（`compute_initial_conditions`、`run_coeval`、`_redshift_loop_generator`…）；只有带子结构的模块才可进入子图（本图是 `compute_initial_conditions` 与 `入口 B`），层带不可进入。
- **按要素种类着色**：节点类型扩到六类要素，配色与语义一一对应——函数/过程（method，紫）、驱动/入口（driver，蓝）、参数/变量（variable，青）、数据与场（dataset，天蓝）、交付产物（artifact，品红）、装饰容器与层（group，墨绿）；图例只列当前图谱实际出现的类型。
- **交付产物不再作为方框**：产物节点解散，其名称转写到「生产 → 消费」的边标签上（箭头文本）；`图一`/`图二` 时代画在箭头上的青色产物标签回到箭头文本这一形态。

## Capabilities

### New Capabilities

- `graphify-subgraph-tabs`: 子图标签页导航——标签栏、装饰容器/模块可见性规则、进入子图入口（双击/属性页按钮）、标签页独立视口状态、URL 同步，以及主图五层模块结构的数据形态。

### Modified Capabilities

- `graphify-canvas-appearance`: 「未展开分支标记」要求变更——模块改为「可进入子图」标记（▸N 计数徽标 + 双击/按钮进入），并新增「装饰容器样式」要求（复合框、无徽标、无进入交互）。
- `graphify-canvas-layout`: 「展开与收起后的重排」要求变更——原地展开/收起被标签页导航取代，重排发生在各标签页可见内容内，装饰框自动合围子节点。

## Impact

- `Graphify/web/src/render/cytoscape-renderer.ts`：可见性规则（装饰框递归内联、模块紧凑）、复合渲染、交互回调重构（移除 focusPath/expandState）。
- `Graphify/web/src/state/graph-store.ts`：新增标签页状态（tabs/active/open/close/activate）与 URL 同步。
- `Graphify/web/src/ui/App.tsx`、Inspector、工具栏：标签栏 UI、进入子图按钮、按标签页整理布局。
- `Graphify/scripts/`：新增数据重构脚本；`normalize-layout.mjs` 支持按标签页（scope）整理与装饰框合围。
- `Graphify/data/graph.json`：结构重构（节点数 70→69，仅解散「图二」一个根层大框；内容节点与边全部保留）。
- 不涉及 server API 变更、无新依赖。
