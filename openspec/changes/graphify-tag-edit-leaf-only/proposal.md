## Why

属性面板里「全局标签」长了两套实现：**带叉号的胶囊行**（`NodeTagEditor`，每个已归属标签一个 ×，点了即摘）与下面的**明细区块**（`NodeTagSection`，标签名 + 条数 + 展开明细）。同一份归属被列两遍，两处标题都叫「全局标签」，用户看到的是"同一个东西有两个出口"。

更要紧的是第二件事：这两套入口**对谁都开放**。而按既有口径（主规格 `graphify-graph-annotations`「标签只服务参数」），**有子节点的模块 MUST NOT 自己挂标签**——它的标签是子图里叶子标签的并集、由前端派生展示。物理链生成物正是这样：12 个块里 11 个带标签（`block:galaxy` 19 个、`block:halobox` 18 个），全部是成员标签的并集。于是现在这个界面允许用户手改一个**派生值**：改完与成员的并集对不上，红点、筛选与明细就自相矛盾，而且没有任何东西会拦住它。

## What Changes

- **撤销带叉号的那处实现**（`NodeTagEditor` 的胶囊行）：已归属标签不再以"胶囊 + ×"列出——标签名与明细只在下方区块出现一次。
- **面板里只剩一个标签区块**：归属编辑入口（「+ 标签」Popover：从注册表多选、可当场新建）挪进区块标题行；区块内仍是"按标签展开明细"。
- **新增约束（用户口径 2026-09-30）**：增删标签**只对叶子模块开放**。判据只有一条——**有没有子图**：没有直系子节点就是叶子（可增删）；有子图的节点（能「进入子图」的模块 / 块，`childCount > 0`）一律**只读**，界面上写明它的标签来自子图成员、以及要改就去成员上改；容器（大框）沿用既有的"不参与标签"。
- **"建了子图就重新继承"（用户口径 2026-10-01）**：有子图的节点显示的标签 MUST 是其**子树叶子标签的并集**，**现算**（渲染时算，不写回、不缓存）：叶子一改就跟着变；叶子被删光（子图被整个删掉）就**没有标签**，不保留删之前那份；它自己那份"建子图之前"的标签不参与显示（用户口径：本来的属性没那么重要）。明细按叶子归并并标明来源。这一半今天在画布页是**缺的**（`data/graph.json` 里 15 个有子方标签全为空、前端也没有聚合代码），不补上则"标签来自子图成员"那句只读文案无从验。
- **判据只写一份**：可编辑性与"并集怎么算"各收敛成一个纯函数（`canEditNodeTags` / `inheritedTagsOf`），组件与自检共用，不允许在页面里各写一遍。
- **自检加断言**：把上述身份逐条验一遍，独立重算一遍并集比对，并断言面板里只有一个标签区块（防止第二处实现再长回来）。

**BREAKING**：无对外数据格式变更；但界面上"点 × 摘标签"这个手势消失，摘标签改为在「+ 标签」Popover 里取消勾选。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `graphify-global-tags`: 改写「属性面板标签区块与标签编辑」——明确**一个**标签区块（不是两处），把标签增删的开放范围收紧为"有没有子图"这一条判据（叶子可增删，其余只读），并要求只读态必须**列出并集**而不是空清单。
- `graphify-graph-annotations`: 把「标签只服务参数」里那句"由前端派生展示"写成可验的算法——有子图者的标签 = **当前**子树叶子标签的并集（**现算、不落地、不缓存**：跟着叶子变，叶子都被删光就是空），明细按叶子归并并标明来源。

## Impact

- `Graphify/src/components/NodeTags.tsx`：去掉胶囊行与 `X` 图标；`NodeTagSection` 标题行承载「+ 标签」；空态与只读态文案分叉。
- `Graphify/src/components/Inspector.tsx`：删掉顶部那处 `Field plain label="全局标签"`（第 605–616 行），可编辑性作为入参传给标签区块；`标签数` 那行的提示语改为指向唯一区块。
- `Graphify/src/lib/`（新增判据）：`canEditNodeTags(node, childCount)`（谁能增删）与 `inheritedTagsOf(nodes, id)`（当前子树叶子并集 + 明细归并）两处口径，组件与自检共用。
- `Graphify/src/components/PhysicsChainView.tsx`：物理链页本来就把编辑类回调接成只读提示，改动后只读呈现与它的只读通道一致（不再显示"看着能改"的控件）；块标签仍读生成物自带的那份并集（那个口径归 `graphify-chain-param-sidebar`）。
- `Graphify/scripts/`：新增/扩一条自检断言（叶子可编、有子图只读、容器只读、面板只有一个标签区块、画布页并集独立重算），跑在现有 `npm run check:*` 通道里。
- 不涉及数据**格式**、服务端校验与生成器产物（`physics-chain.json` 不动）；`data/graph.json` 里的节点数据也不动（并集只在视图现算，MUST NOT 写回 `tags` / `tagDetails`）。
