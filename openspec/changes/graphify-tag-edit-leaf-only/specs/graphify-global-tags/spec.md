## MODIFIED Requirements

### Requirement: 属性面板标签区块与标签编辑

属性面板 MUST **只有一个**标签区块：列出当前节点的标签（名称 + 说明），并可按标签展开明细条目（条目含 `label`、`kind`、`note`、可点开的 `ref`）。同一份归属 MUST NOT 在面板里列出两遍——归属编辑入口（「+ 标签」）与明细 MUST 落在同一个区块里，该区块的标题 MUST 只出现一次。标签编辑 MUST 从注册表里多选，并 MUST 支持新建标签（新建即写入注册表并归属到该节点）。自由文本标签输入 MUST 被移除（避免出现「注册表外的标签」）。

标签增删对谁开放，MUST 只有一条判据：**有没有子图**。没有直系子节点的模块是叶子，叶子自持标签、可增删；有子图的节点（直系子节点数 > 0，即界面上能「进入子图」的模块 / 块）MUST 只读：MUST NOT 提供勾选、新建或摘除入口，以免手改出来的归属与并集对不上。容器（大框）不参与标签，MUST 同样不可增删。只读态 MUST 说明理由（标签来自子图成员）并指出该去成员上改，MUST NOT 只把控件灰掉而不给话。

只读节点的标签区块 MUST 列出**它的标签**，而不是空着：有子图的节点显示的 MUST 是其子树叶子标签的并集（现算，见 `graphify-graph-annotations`「标签只服务参数」：跟着叶子变，叶子都没了就是空），明细按叶子归并；MUST NOT 因为"不可编辑"就把清单省掉——否则"标签来自子图成员"这句话无处可验。

#### Scenario: 面板里只有一个标签区块

- **WHEN** 在属性面板选中一个带标签的节点
- **THEN** 面板里 MUST 只有一个标签区块（一个标题、一份标签名清单）；已归属标签 MUST NOT 另以"可逐个摘除的胶囊"等形式再列一遍

#### Scenario: 多选归属

- **WHEN** 在一个**叶子模块**的属性面板里多选两个标签
- **THEN** 两个标签都归属到该节点，画布上对应的红点图标随勾选状态出现

#### Scenario: 新建标签即注册

- **WHEN** 在**叶子模块**的属性面板输入一个注册表里没有的标签名并确认
- **THEN** 该标签进入注册表（带说明占位）并归属到当前节点；其它节点也可以再选它

#### Scenario: 摘标签不必靠叉号

- **WHEN** 在**叶子模块**的属性面板里取消勾选一个已归属的标签
- **THEN** 该标签从该节点摘除（画布红点与明细同步）；这一步 MUST NOT 依赖"胶囊上的叉号"这类额外控件

#### Scenario: 有子图的节点只读

- **WHEN** 选中一个直系子节点数 > 0 的模块（或物理链页的块）
- **THEN** 标签区块 MUST NOT 提供勾选、新建或摘除入口；它显示的标签 MUST 是子树叶子标签的并集（现算），MUST 如实列出并可展开明细，MUST NOT 因为只读而列成空

#### Scenario: 只读的清单跟着叶子变

- **WHEN** 在一个叶子上摘掉某个标签，而它有子图的祖先正被选中
- **THEN** 祖先那个只读区块里的标签清单 MUST 立刻少掉这一条（若它下面的叶子都不再带任何标签、或叶子被删光，并集即为空）

#### Scenario: 只读要说清理由

- **WHEN** 查看上述只读节点的标签区块
- **THEN** MUST 有一句话说清它的标签来自子图成员，并指出要改就去成员上改

#### Scenario: 容器不可增删

- **WHEN** 选中一个容器（大框）
- **THEN** 标签区块 MUST NOT 提供增删入口（容器不参与标签，与既有"容器只作分组"口径一致）
