## MODIFIED Requirements

### Requirement: 层级连线与语义关系的样式区分

层级连线 MUST 在视觉上区别于语义关系：MUST NOT 绘制箭头，MUST 使用不高于语义关系的视觉权重（更细的实线、更低的饱和度），且 MUST NOT 使用语义关系用于表达类型的虚线或点线语义。语义关系 MUST 继续以线型区分类型（实线 = 必执行、虚线 = 条件 / 可选、点线 = 其它）。画布图例 MUST 同时列出「层级连线」与语义关系类型的区别。

语义关系的**方向箭头 MUST 默认不绘制**，其显现 MUST 与关系名同一时机，共四种，且 MUST NOT 引入这四种之外的时机：

- 指针悬停在某个**模块**（非装饰容器）上时，该模块的出入关系显现箭头；
- 指针悬停在**某条关系**上时，该条显现箭头；
- **选中**某条关系时，该条显现箭头；
- 打开工具条的**「常显边标签」**开关时，全部可见关系的箭头一并显现。

**无向关系**（`directed` 为假）MUST 在任何时机都不绘制箭头——包括上述四种时机全部生效时。关系名的显示时机与默认状态 MUST NOT 因本要求改变（仍为悬停模块 / 悬停该条 / 选中该条 / 「常显边标签」开关）。

#### Scenario: 层级连线无箭头且更淡

- **WHEN** 同时观察一条层级连线与一条依赖关系（指针未悬停任何模块或关系、未选中、常显开关为关）
- **THEN** 层级连线没有箭头且视觉权重更低；依赖关系此时同样不画箭头，仍以线型区分类型

#### Scenario: 默认视角下画布上没有箭头

- **WHEN** 打开图谱，未悬停任何模块或关系，且「常显边标签」开关为关
- **THEN** 画布上不存在三角箭头；语义关系仍以线型区分类型，层级连线同样无箭头

#### Scenario: 悬停模块时它的出入关系显出箭头

- **WHEN** 把指针停在一个模块上
- **THEN** 该模块的出入关系显示箭头与关系名，画布上其它关系仍无箭头

#### Scenario: 悬停某条关系时该条显出箭头

- **WHEN** 把指针停在一条语义关系上
- **THEN** 该条关系显示箭头与关系名，其余关系不受影响

#### Scenario: 选中某条关系时该条显出箭头

- **WHEN** 选中一条语义关系
- **THEN** 该条关系保持显示箭头，直到取消选中

#### Scenario: 打开常显边标签时全部显现箭头

- **WHEN** 打开工具条的「常显边标签」开关
- **THEN** 当前画布上全部可见的语义关系都显示关系名与箭头，可一次读完整条数据流的流向

#### Scenario: 无向关系在任何时机都不显箭头

- **WHEN** 一条无向关系的一端模块被悬停，或该关系被悬停 / 选中，或打开「常显边标签」开关
- **THEN** 该条关系始终不绘制箭头

#### Scenario: 层级连线始终无箭头

- **WHEN** 悬停一个模块，或打开「常显边标签」开关
- **THEN** 该模块的层级连线仍不绘制箭头

#### Scenario: 图例含层级连线

- **WHEN** 打开画布图例
- **THEN** 其中除节点类型与关系类型外，还包含一条说明层级连线样式的条目，且与画布实际渲染一致
